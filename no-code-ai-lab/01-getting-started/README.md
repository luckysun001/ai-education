## 第二步：你的第一个自动化工作流（5 分钟完成）

我们来做一个最简单，但是非常实用的自动化：

**每天早上 8 点，AI 自动给你发一条微信，告诉你今天的天气、今日要闻，以及一句鼓励的话。**

全程不用写代码，5 分钟搞定。

---

### 准备工作

你需要：
1. 一个 Make.com 的账号（免费版就行）
2. 一个豆包或者 GPT 的 API Key
3. 一个 Server 酱的账号（用来发微信消息，免费的）

Server 酱注册地址：https://sct.ftqq.com/，注册完就能拿到你的 SendKey，用这个就能给自己发微信消息，非常方便。

---

### Step 1: 新建一个 Scenario（工作流）

1. 登录 Make.com
2. 点击右上角的 **+ Create a new scenario**
3. 你会看到一个空白的画布，我们来一步步加节点

---

### Step 2: 第一个节点：定时触发

我们要让这个工作流每天早上 8 点自动运行。

1. 点击画布中间的 **+** 号，搜索 **Schedule**
2. 选择 **Trigger** 下面的 **Every day at**
3. 设置时间：8:00，时区选 **Asia/Shanghai**（北京时间）
4. 点击 **OK**

第一个节点就做好了，意思是：每天早上 8 点，这个工作流就会自动启动。

---

### Step 3: 第二个节点：调用大模型生成内容

接下来，我们让 AI 生成今天的内容：天气、新闻、鼓励的话。

1. 点击第一个节点右边的 **+** 号，添加下一个节点
2. 搜索 **OpenAI**（或者你用的其他大模型）
3. 选择 **Action** 下面的 **Create a Completion / Chat**
4. 配置这个节点：
   - API Key：填入你的 OpenAI / 豆包 API Key
   - Model：选 gpt-4o 或者你用的模型
   - Prompt：填入下面这段提示词

```
你是我的私人早安助手。
请帮我生成今天的早安消息，包含三个部分：

1. 今天北京的天气怎么样？温度多少？有没有雨？要不要带伞？
2. 今天的 3 条重要新闻，国内国际各一条，科技圈一条，每条不超过 30 字
3. 一句简短的、鼓励人的话，元气满满的，适合今天的心情

整体语气要亲切自然，像朋友一样，不要太官方。
总长度不要超过 300 字。
```

5. 点击 **OK**

第二个节点就做好了，意思是：工作流启动之后，自动调用大模型，生成我们想要的内容。

---

### Step 4: 第三个节点：给你发微信

最后一步，把 AI 生成的内容，用微信发给你自己。

1. 点击第二个节点右边的 **+** 号，添加第三个节点
2. 搜索 **HTTP**，选择 **Action** 下面的 **Make a request**
3. 配置这个节点：
   - URL：`https://sctapi.ftqq.com/你的SendKey.send`（把你的 SendKey 填进去）
   - Method：`POST`
   - Body type：`Multipart/form-data`
   - Fields：添加两个字段：
     - `title`：值填 `☀️ 今日早安`
     - `desp`：值选择上一个节点输出的 **Text Content**，也就是 AI 生成的内容
4. 点击 **OK**

第三个节点也做好了！

---

### Step 5: 测试一下，看看能不能跑通

1. 点击右上角的 **Run once** 按钮
2. 你会看到三个节点依次变绿
3. 打开你的微信，看看有没有收到 Server 酱发来的消息

如果收到了，恭喜！🎉
你的第一个 AI 自动化工作流就做成功了！

以后每天早上 8 点，它都会自动给你发早安消息，再也不用你管了。

## 常见问题

### Q: 我不会英语，Make.com 都是英文的，看不懂怎么办？
A: 没关系，用 Chrome 浏览器的自动翻译功能，整个页面翻译成中文就行，不影响使用。

### Q: 免费版够用吗？
A: Make.com 的免费版每个月可以运行 1000 次操作，个人使用完全足够了。等你玩熟了，用的多了，再考虑升级付费版也不迟。

### Q: 我没有 API Key 怎么办？
A: 豆包的 API 很便宜，几块钱就能用很久，注册一个豆包账号，开通 API 就行。不想花钱的话，也可以用很多其他免费的大模型 API。

### Q: 跑失败了怎么办？
A: 很正常，第一次做很容易哪里配置错了。仔细看报错信息，一步一步检查，看看哪个节点出问题了，改一改再试。多试几次就成了。
