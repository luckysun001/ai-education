# 自动化工作流篇

> 把你每天的重复工作全部自动化，
> 一次投入几个小时，以后每天帮你省时间，永久回报。

---

## 什么是自动化工作流？

简单说就是：**如果发生了 A 事情，就自动做 B 事情。**

比如：
- 如果有人给我发邮件，就自动总结一下，微信发给我
- 如果有人在 GitHub 给我提 Issue，就自动记到我的 Notion 里
- 如果到了每天晚上 6 点，就自动把今天的群聊消息总结一下发给我
- 如果 RSS 订阅有更新，就自动让 AI 总结一下，发给我

所有这些，都不用你写代码，
用 Make/n8n 这种工具，拖拖拽拽几个节点，连起来就行。

你只要花一次时间把工作流搭好，
以后它就会 7x24 小时自动运行，
永远帮你干活，不用你管。

---

## 自动化工作流的核心思想

### 1. 任何你每天都要做的重复工作，都应该自动化。

如果一件事，你每天都要花 10 分钟做，
花 2 个小时把它自动化，
4 个月就回本了，之后就是纯赚，每天帮你省 10 分钟。

越常做的事情，越值得自动化。

---

### 2. 不要追求完美，先跑起来，再慢慢优化。

很多人做自动化，总想一开始就做一个完美的、能处理所有情况的工作流，
结果做了一个月还没做完，最后放弃了。

不要这样。

先做一个最简单的版本，能跑通，能解决 80% 的问题就行，
剩下的 20% 特殊情况，你手动处理就好。
先用起来，有问题再慢慢优化。

先完成，再完美。

---

### 3. 自动化不是为了让你变得更忙，而是为了让你有更多时间做重要的事。

很多人做了自动化之后，省下来的时间又用来做更多的重复工作，
结果比之前更忙了，这就本末倒置了。

省下来的时间，应该用来：
- 做需要思考和创造力的工作
- 学习和提升自己
- 陪家人，休息，享受生活

不要把自己变成效率的奴隶。

## 工作流 1：邮件自动总结和提醒

**适合人群**：每天收到很多邮件，没时间一封一封看的人。

**能省多少时间**：每天 30-60 分钟。

**实现的效果**：
所有发到你邮箱的邮件，AI 自动帮你总结内容，提取重点，
然后把摘要发到你的微信上，重要的邮件标红提醒。
你不用每天打开邮箱刷新了，有用的邮件自然会来找你。

---

### 需要的工具
1. Make.com / n8n
2. 你的邮箱（Gmail、QQ 邮箱、企业邮箱都可以）
3. 大模型 API Key
4. Server 酱 / 其他发微信消息的工具

---

### 搭建步骤

#### Step 1: 邮件触发节点
1. 新建一个 Scenario
2. 第一个节点选 **Email** 或者 **Gmail**
3. 选择 **Watch emails**，也就是有新邮件的时候自动触发
4. 配置你的邮箱账号，授权给 Make 访问
5. 设置多久检查一次新邮件：建议 5 分钟或者 10 分钟

#### Step 2: AI 总结邮件内容
添加第二个节点，调用大模型：

```
你是我的邮件助理。
这是我收到的一封邮件：

发件人：{{1.from.name}} <{{1.from.address}}>
主题：{{1.subject}}
内容：
{{1.text}}

请帮我做以下事情：

1. 用一句话总结这封邮件是说什么的，不超过 50 字
2. 提取邮件里的关键信息：时间、地点、人物、需要我做的事情、截止日期
3. 判断这封邮件的重要程度：
   - 🔴 非常重要，需要马上处理
   - 🟡 一般重要，今天之内处理就行
   - 🟢 不重要，有空再看，甚至可以不用看
4. 如果有需要我回复的，给我写一个简单的回复草稿，我改改就能发

整体要简洁，不要废话，重点突出，让我扫一眼就知道怎么回事。
```

#### Step 3: 把总结发到微信
添加第三个节点，HTTP 请求，调用 Server 酱发送消息：
- Title：`📧 {{邮件重要程度}} 新邮件：{{邮件主题}}`
- Content：AI 生成的总结内容

#### Step 4: 测试运行
给自己发一封测试邮件，看看能不能收到总结，没问题就打开自动运行。

---

### 进阶玩法
- 不同重要程度的邮件，发不同的地方：非常重要的打电话提醒你，不重要的只发到飞书
- 根据发件人和内容，自动给邮件打标签，分类归档
- 识别垃圾邮件和广告邮件，直接删掉，不用告诉你
- 如果是客户的邮件，自动记到 CRM 里，并且提醒销售跟进

## 工作流 2：群聊消息自动摘要和精华整理

**适合人群**：加了很多群，每天几百条消息，看不过来的人。

**能省多少时间**：每天 1-2 小时。

**实现的效果**：
每天固定时间，自动把你关心的几个群的聊天记录全部爬下来，
AI 自动总结，分类，提炼出精华和重要的信息，
然后给你发一个摘要，哪些是重要的，哪些是八卦，哪些有价值信息，
你不用爬几百条楼了，看 5 分钟摘要就知道今天群里都发生了什么。

---

### 需要的工具
1. Make.com / n8n
2. 飞书机器人 / 企业微信机器人（用来接收群消息）
3. 大模型 API Key
4. 群聊消息导出工具

---

### 搭建步骤

#### Step 1: 收集群聊消息
把群里的消息都转发到机器人那里，或者用导出工具导出聊天记录。
最简单的方式：用飞书或者企业微信，把群里的消息都同步到一个专门的频道里。

#### Step 2: 定时触发，每天总结一次
每天晚上 7 点，或者你下班的时候，自动运行：
1. 把过去 24 小时的所有群聊消息都拿出来
2. 扔给大模型做总结

给 AI 的 Prompt：
```
这是我们群今天的所有聊天记录：

{{把所有聊天记录贴在这里}}

请帮我做总结和整理：

1. 今天大家主要聊了哪几个话题？按热度排序，每个话题一句话总结。
2. 重要信息：哪些信息是重要的，所有人都应该知道的？
   - 公告、通知、重要决定
   - 有价值的观点和经验分享
   - 需要大家跟进的事情
3. 资源和干货：今天大家分享了什么有用的链接、资料、工具？
4. 可以忽略的内容：哪些是灌水、表情包、闲聊，不用看的。
5. 金句和有趣的内容：有没有什么有意思的话，或者搞笑的段子？

整理成清晰的结构，简洁明了，重点突出，
让没有看过群聊的人，看了这个总结就知道今天都发生了什么。
总长度不要超过 500 字。
```

#### Step 3: 把总结发回群里，或者发给你自己
每天自动发，大家再也不用爬楼了。

---

### 进阶玩法
- 实时监控群聊，如果有人提到你的名字，或者提到你关心的关键词，马上提醒你
- 自动整理群里的精华内容，每周做一次周报，每月做一次月报
- 自动提取群里分享的链接和资源，存到你的 Notion 知识库里面
- 有人在群里问已经回答过的问题，AI 自动回答，不用每次都有人重复解答

## 工作流 3：RSS 订阅和文章自动总结

**适合人群**：订阅了很多博客和 Newsletter，没时间看的人。

**能省多少时间**：每周 3-5 小时。

**实现的效果**：
你订阅的所有博客、公众号、Newsletter 有更新的时候，
AI 自动帮你读完整篇文章，给你写一个 300 字的摘要，
告诉你这篇文章主要讲了什么，核心观点是什么，值不值得全文阅读，
然后把所有文章的摘要打包发给你，
你扫一眼就知道哪些值得看，哪些可以直接跳过。

---

### 需要的工具
1. Make.com / n8n
2. RSS 订阅节点
3. 大模型 API Key
4. Notion / 飞书文档 / 微信

---

### 搭建步骤

#### Step 1: RSS 触发节点
1. 第一个节点选 **RSS**
2. 把你所有订阅的 RSS 地址都加进去
3. 设置每小时检查一次有没有新文章

#### Step 2: 抓取文章全文
很多 RSS 只输出摘要，不输出全文，
加一个节点，用 AI 爬虫或者浏览器工具打开文章链接，抓取全文。

#### Step 3: AI 总结文章
```
请帮我总结这篇文章：

标题：{{文章标题}}
作者：{{作者}}
原文：
{{文章全文}}

请帮我做总结：

1. 一句话总结：这篇文章主要讲了什么？
2. 核心观点：作者最主要的 3-5 个观点是什么？
3. 有没有什么反常识、刷新认知的内容？
4. 有没有什么可以直接拿来用的方法论、工具、建议？
5. 推荐指数：⭐️⭐️⭐️⭐️⭐️，打个分
6. 阅读建议：这篇文章值得花时间全文阅读吗？还是看摘要就够了？

总结要简洁，客观，不要加入你自己的观点，忠实于原文。
总长度不要超过 300 字。
```

#### Step 4: 把所有文章的汇总到一起，发给你
- 可以每天发一次，也可以每周发一次
- 可以存到 Notion 里，也可以发微信，也可以发邮件

---

### 进阶玩法
- 按主题分类，不同类型的文章存到不同的地方
- AI 自动给文章打标签，方便以后搜索和整理
- 相似的文章自动聚类，相同主题的放在一起
- 你特别喜欢的作者的文章，自动高亮提醒
- 每周做一次阅读周报，告诉你这周都有什么值得看的

## 工作流 4：客户反馈自动收集和分析

**适合人群**：做产品、做运营、做销售，每天收到很多用户反馈的人。

**能省多少时间**：每周 5-10 小时。

**实现的效果**：
所有渠道（App 评论、应用商店、社群、客服、工单系统）的用户反馈，
自动全部收集到一起，
AI 自动分类、打标签、分析情绪、提取核心观点，
自动生成日报、周报，告诉你用户最近在骂什么，在夸什么，最想要什么功能。

你不用再去各个地方看用户反馈了，AI 都帮你整理好了。

---

### 需要的工具
1. Make.com / n8n
2. 各个渠道的 API 或者 Webhook
3. 大模型 API Key
4. Notion / Airtable 用来存数据

---

### 搭建步骤

#### Step 1: 从各个渠道收集反馈
把所有能收到用户反馈的地方，都接到 Make 里面来：
- App Store / 安卓应用市场评论
- 社群里用户说的话
- 客服系统的工单
- 问卷和调研的结果
- 产品里的反馈入口

每个渠道有新反馈的时候，就自动触发工作流。

#### Step 2: AI 分析每一条反馈
```
这是一条用户反馈：

{{用户反馈内容}}
用户是谁：{{用户信息}}
来自哪个渠道：{{渠道}}

请帮我分析：

1. 情绪判断：😡 负面 / 😐 中性 / 😊 正面
2. 分类：这是 Bug 反馈 / 功能需求 / 体验问题 / 咨询 / 表扬 / 其他
3. 关键词：提取 3-5 个关键词
4. 核心观点：用户到底想表达什么？一句话总结
5. 严重程度：🔴 很严重，很多人会遇到 / 🟡 一般 / 🟢 个别情况
6. 如果是 Bug，大概是什么问题？能不能复现？
7. 如果是需求，用户想要的到底是什么？有没有什么替代方案？
```

#### Step 3: 把所有结构化的数据存到数据库里
每条分析好的反馈，存到 Notion 或者 Airtable 里，
字段就是上面分析出来的：情绪、分类、关键词、核心观点、严重程度。

#### Step 4: 自动生成日报和周报
每天早上自动把前一天的所有反馈做个汇总：
- 多少条正面，多少条负面
- 大家骂得最多的是什么问题
- 大家提得最多的需求是什么
- 跟之前比，有没有变好还是变差

发给产品团队和运营团队，大家就知道接下来应该重点做什么了。

---

### 进阶玩法
- 同一个问题很多人提的时候，自动报警，发消息给相关负责人
- 用户骂得特别狠的反馈，直接@产品负责人，马上处理
- 自动把相似的反馈合并，告诉你有多少人提了同一个问题
- 有新功能上线之后，监控用户反馈，看看大家是夸还是骂

## 工作流 5：社交媒体监控和舆情提醒

**适合人群**：做市场、做品牌、做 PR，需要监控品牌舆情的人。

**能省多少时间**：每天 1-2 小时。

**实现的效果**：
网上任何地方提到了你的公司、你的产品、你的品牌、你的名字，
AI 自动帮你抓下来，分析是正面还是负面，
负面的马上提醒你，正面的可以转发和互动，
你不用每天搜八百次了，有情况自动找你。

---

### 搭建思路
1. 监控各个平台：微博、知乎、小红书、推特、论坛等等
2. 提到你的关键词的时候，自动触发
3. AI 分析情绪和内容，判断重要程度
4. 重要的、负面的，马上发消息提醒你
5. 不重要的，攒着每天给你发一次汇总

这个的结构和用户反馈那个差不多，就不重复写了。

## 做自动化的通用技巧和避坑指南

### 1. 从最简单的开始，不要一开始就做复杂的

先做那个最简单、最容易跑通、马上就能看到效果的，
先建立信心，尝到甜头，你才有动力继续做更复杂的。

不要一开始就想做一个超级复杂的、处理所有情况的工作流，
大概率你做不完，最后放弃了。

---

### 2. 一定要加错误处理和报警

任何自动化工作流，都会有出问题的时候，
比如某个 API 挂了，某个节点超时了，某个格式不对了。

一定要加错误处理：
- 如果某个节点失败了，不要整个工作流就死在那里，没人知道
- 失败了要给你发个消息，告诉你哪个工作流出问题了
- 重要的工作流，失败了重试几次，还不行再报警

---

### 3. 不要 100% 依赖自动化，保留人工干预的能力

任何自动化，都不可能 100% 准确，
AI 会犯错，API 会挂，会有各种你想不到的特殊情况。

永远要有人工检查和干预的机制。
尤其是涉及到对外发消息、涉及到钱的工作流，
发之前最好人工看一眼，确认没问题再发。

自动化是帮你省时间，不是让你当甩手掌柜。

---

### 4. 做好日志和记录

每个工作流每次运行，都要记录下来运行结果，
出了问题要能查到是哪一步出了问题，
不要出了 bug 两眼一抹黑，不知道怎么回事。

---

### 5. 定期回顾和优化

你做的自动化工作流，不是做完就完了，
要定期回头看看：
- 这个工作流现在还用吗？是不是已经不需要了？
- 哪些地方经常出问题？能不能优化一下？
- 有没有什么新的工具和玩法，可以做得更好？
- 现在的成本是不是太高了？能不能降一降？

自动化是一个持续优化的过程，不是一劳永逸的。
