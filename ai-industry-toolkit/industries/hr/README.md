# 人力资源（HR）行业 AI 应用指南

适合：HR、招聘、培训、组织发展、管理者、创业者

AI 正在深刻改变人力资源工作，从招聘、培训到绩效管理、员工关系，都能大幅提升效率，让 HR 从行政事务转向更有价值的战略伙伴。

---

## 这个行业可以用 AI 做什么

### 场景 1：招聘和人才选拔

**适用人群**：招聘专员、HRBP、用人经理

**能解决的问题**：
- JD 写不好，吸引不到优秀的人
- 简历太多，看不过来
- 面试不知道问什么
- 候选人体验不好
- 招人慢，赶不上业务需求

**具体用法**：

#### 1.1 写职位描述（JD）

```
你是一位资深的招聘专家，有 10 年的互联网/高科技行业招聘经验，
特别擅长写有吸引力、能吸引到优秀候选人的 JD。

我们要招一个 [职位名称]，
所属部门是：[哪个部门]
汇报给：[谁]
工作地点是：[城市]

这个职位是做什么的：
[简单描述这个岗位的核心职责，要解决什么业务问题]

我们理想的候选人是：
[描述你想要什么样的人，经验、技能、性格特质等]

我们公司和团队的特点是：
[简单介绍公司，比如：创业公司、扁平管理、技术氛围好等]

请帮我写一份完整的 JD：

一、职位标题
   - 给 3 个不同风格的版本
   - 哪个是最推荐的？为什么？

二、职位吸引点（放在最前面，抓眼球）
   - 这个职位最吸引人的地方是什么？
   - 候选人为什么要来做这个工作？
   - 写 3-5 个核心亮点，用 bullet point

三、团队和公司介绍
   - 我们是一个什么样的团队？
   - 做的事情有什么价值？
   - 加入我们，你能获得什么成长？

四、你将要做什么（岗位职责）
   - 分点写，6-8 条比较合适
   - 不要写得太假大空，要具体
   - 按重要性排序
   - 让人看完就知道每天大概要干什么

五、我们希望你有什么（任职要求）
   - 分「必须有」和「加分项」
   - 必须有：3-5 条，达不到的就不要投了
   - 加分项：3-5 条，有了更好，没有也没关系
   - 不要写太多要求，把真正核心的写出来就行，要求太多没人投

六、我们能提供什么（薪酬福利）
   - 薪资范围（不要写「面议」，会被骂，给个范围）
   - 五险一金、年终奖这些标配就不用说了
   - 说点我们独有的、特别的福利
   - 学习成长机会？晋升空间？团队氛围？

七、常见问题解答（候选人最关心的几个问题）
   - 比如：加班多吗？要不要坐班？有没有远程机会？
   - 直接写出来，减少沟通成本

八、最后，给我们一些招聘建议
   - 这个职位的候选人一般在哪些地方活跃？
   - 去什么渠道挖人最好？
   - 搜索这个职位的简历，用什么关键词组合？
   - 什么样的简历应该重点看？
   - 面试要重点考察什么？

JD 写作要求：
- 语气真诚，不要官方，像和朋友聊天一样
- 不要有废话，每一句都要有信息量
- 不要有「吃苦耐劳、抗压能力强」这种鬼话，大家都知道是什么意思
- 不要性别歧视、年龄歧视，不要写「35 岁以下」「男生优先」
- 字数控制在 800-1200 字
```

#### 1.2 简历筛选和初筛评估

```
你是一位经验丰富的技术面试官/招聘专家，
看过上万份简历，很会看简历，知道什么样的人靠谱。

我们要招 [职位名称]，
这个职位的核心要求是：
1. [要求 1]
2. [要求 2]
3. [要求 3]
...

这是一份候选人的简历：
[粘贴简历内容]

请帮我做简历初筛和评估：

一、整体印象和初步判断
1. 这份简历整体怎么样？符合我们的要求吗？
2. 要不要约面试？给个明确的建议：✅ 强烈推荐 / 🟡 可以看看 / ❌ 算了吧
3. 如果要打分，1-10 分，打几分？为什么？

二、简历亮点
1. 哪些地方是加分项？
2. 哪些经历特别匹配我们的要求？
3. 哪些点让你觉得这个人可能不错？

三、简历疑点和风险点
1. 哪些地方看起来不对劲？
2. 有没有什么背景/经历可能有问题？
3. 有没有 gap？有没有频繁跳槽？
4. 有没有什么夸大其词的地方？
5. 哪些点面试的时候一定要问清楚？

四、匹配度分析
1. 硬技能匹配度：（1-10 分）
   - 哪些技能匹配？哪些不匹配？
2. 经验匹配度：（1-10 分）
   - 做过的事情和我们要他做的事情匹配吗？
3. 可能的成长潜力：（1-10 分）
   - 这个人潜力大不大？

五、面试重点考察的问题
针对这份简历，面试的时候一定要问什么问题？至少 10 个：
1. 考察硬技能的问题
2. 考察软技能的问题
3. 验证简历真实性的问题
4. 排查刚才发现的风险点的问题

六、其他建议
- 面试的时候要注意什么？
- 这个人可能会关心什么问题？我们要怎么吸引他？
- 如果这个人不行，我们应该招什么样的？
```

#### 1.3 面试题库和面试指南

```
你是一位资深的 [技术 / 产品 / 运营] 面试官，
面过几百个人，知道怎么通过面试看出一个人真正的水平。

我们要招 [职位名称]，
这个职位最核心的能力要求是：
1. [能力 1]
2. [能力 2]
3. [能力 3]
...

请帮我设计一套完整的面试题库和面试指南：

一、整体面试流程设计
1. 整个面试分几轮？每轮多久？
2. 每轮面试重点考察什么？
3. 哪一轮是一票否决的？
4. 每轮的面试官应该是什么角色？

二、行为面试题（STAR 原则）
针对每个核心能力，设计 3-5 个行为面试题：
- 考察能力 1 的题目
  1. 请讲一个你 [相关经历] 的例子
  2. 当时是什么情况？你的任务是什么？
  3. 你具体做了什么？
  4. 最后结果怎么样？你学到了什么？
- 考察能力 2 的题目
- ...

对每个问题，说明：
- 这个问题是考察什么的？
- 好的回答是什么样的？
- 不好的回答是什么样的？
- 怎么追问？问哪些细节？

三、专业技能题
- 这个职位最核心的专业问题有哪些？（至少 10 个）
- 从简单到难，分等级
- 每个问题的好答案是什么？坏答案是什么？
- 怎么通过回答判断这个人的真实水平？

四、软技能和价值观考察
1. 怎么考察一个人的沟通能力？
2. 怎么考察执行力和责任心？
3. 怎么考察学习能力和成长潜力？
4. 怎么考察是不是符合我们的企业文化？
5. 有哪些经典的问题？

五、反向提问环节（候选人问我们问题）
1. 优秀的候选人一般会问什么问题？
2. 从候选人问的问题，能看出什么？
3. 哪些问题说明这个候选人是认真的？
4. 哪些问题说明这个候选人可能不太行？

六、面试避坑指南
1. 面试官最容易犯的错误有哪些？
2. 怎么避免「看眼缘」「凭感觉」招人？
3. 怎么避免招进来「面试造火箭，工作拧螺丝」的人？
4. 哪些信号说明这个人不能要？
5. 哪些信号说明这个人是宝藏，一定要抢下来？

七、面试后评估
- 面试完怎么写面试评语？
- 几个面试官意见不一致怎么办？
- 怎么拍板要不要这个人？
- 发 offer 之前还要做什么背景调查？
```

### 场景 2：培训和人才发展

**适用人群**：培训专员、HRBP、部门主管

#### 2.1 培训课程设计和课件制作

```
你是一位企业培训专家，
擅长设计有用、不无聊、员工愿意听、学了能用的培训课程。

我们要做一个关于 [培训主题，如：时间管理 / 跨部门沟通 / 新员工入职培训] 的培训，
培训对象是：[谁，如：入职 1 年以内的新员工 / 中层管理者 / 销售]
培训时长是：[多久，如：半天 / 一天 / 2 小时线上课]
我们希望达到的培训效果是：
[具体说清楚培训完，员工应该能做到什么]

请帮我设计完整的培训课程：

一、课程整体设计
1. 这个培训的核心目标是什么？
2. 学员学完应该能做到什么？
3. 用什么方式培训效果最好？（讲课？互动？案例？练习？）
4. 怎么防止大家上课玩手机、睡觉？

二、课程大纲和时间分配
按时间顺序，把每一分钟都安排好：
- 0-10 分钟：开场破冰，讲什么？怎么调动气氛？
- 10-30 分钟：第一个知识点，讲什么？怎么讲？有没有互动？
- 30-45 分钟：练习/案例讨论
- ... 以此类推，直到结束
- 最后留 15 分钟答疑和总结

每个部分都要说明：
- 内容是什么？
- 教学方式是什么？
- 预计多久？
- 讲师要注意什么？

三、核心知识点讲解
每个重点知识点，都要准备：
1. 概念：用最简单的话讲明白是什么
2. 为什么重要：和他们的工作有什么关系？学了有什么用？
3. 怎么用：具体步骤，1234 怎么做
4. 常见误区：大家最容易犯的错误是什么
5. 真实案例：最好是我们公司自己的例子

四、互动和练习设计
1. 培训过程中可以做什么小游戏/小练习？
2. 怎么调动大家的积极性，不要全程都是讲师在说？
3. 怎么让内向的人也愿意开口？
4. 小组讨论怎么组织？讨论什么话题？

五、案例设计
- 准备 3-5 个真实的案例，最好是我们公司发生过的
- 每个案例怎么讨论？
- 想让大家从中学到什么？
- 讲师怎么引导讨论？

六、课件（PPT）结构建议
- 每一页 PPT 大概讲什么？
- 哪些地方放图？哪些地方放文字？
- 哪些地方可以放视频？
- 每页 PPT 不要超过多少字？

七、培训效果评估
- 怎么知道这次培训有没有用？
- 培训当场怎么评估？
- 培训结束后 1 个月怎么评估效果？
- 怎么收集大家的反馈？

八、后续跟进
- 培训完就结束了吗？
- 怎么让大家学的东西真的用在工作里？
- 怎么巩固培训效果？
```

#### 2.2 新员工入职和导师带教

```
你是一位优秀的团队主管，特别擅长带新人，
新人在你手下成长很快，离职率也低。

我是一位新主管，团队刚来了一个新同事，
背景是：[简单介绍新人的背景]
入职的职位是：[职位]
我是他的直接主管。

请帮我设计前 3 个月的带教计划：

第一个月：适应期
目标：让新人活下来，不迷茫，能融入团队，开始做简单的工作。

第 1 周：
1. 第一天应该做什么？
   - 上午怎么安排？下午怎么安排？
   - 哪些人必须介绍认识？
   - 哪些系统权限必须开通？
   - 哪些文档必须先看？
2. 第一天晚上，我应该和他聊什么？
3. 第一周，每天下班前 15 分钟 1 对 1，应该聊什么？
4. 第一周，怎么判断这个新人是不是合适？有什么危险信号？

第 2-4 周：
1. 第一个任务应该安排什么？难度怎么样？
2. 怎么教他做第一个任务？手把手教到什么程度？
3. 犯错了怎么办？怎么批评怎么鼓励？
4. 怎么让他和团队其他成员熟悉起来？
5. 第一周结束、第二周结束、第一个月结束，分别怎么复盘？

第二个月：成长期
目标：能独立完成常规工作，知道怎么做是对的。

1. 怎么逐步增加任务的难度和复杂度？
2. 什么时候可以放手让他自己做？什么时候还要盯着？
3. 怎么培养他好的工作习惯？（写文档、沟通、汇报等）
4. 怎么教他解决问题的方法，而不是直接给答案？
5. 第一个月和第二个月的 1 对 1，重点应该聊什么？

第三个月：独立期
目标：完全胜任这个职位的工作，能独立负责一块事情。

1. 怎么让他开始独立负责一个完整的项目/模块？
2. 怎么给他更多自主权？
3. 怎么帮他建立在团队里的影响力？
4. 第三个月结束，怎么做转正答辩？
5. 转正之后，接下来的成长方向是什么？

还有一些通用的问题：
- 新人问问题，是马上回答，还是让他先自己想？
- 新人做的东西不符合预期，是直接改，还是让他自己改？
- 新人进度慢，要不要催？怎么催比较好？
- 哪些信号说明这个新人可能不行，要及时止损？
- 哪些信号说明这个新人是好苗子，要重点培养？
- 怎么让新人有归属感，不想离职？
```

### 场景 3：绩效管理和沟通

**适用人群**：所有管理者、HRBP

#### 3.1 绩效反馈和沟通话术

```
你是一位领导力教练，
特别擅长教管理者怎么和员工做绩效沟通，
怎么说既能让员工接受，又能激励员工改进，还不会伤感情。

我要和一个员工做绩效面谈，
这个员工的情况是：[详细描述员工的情况，比如：
  - 平时工作挺努力的，但就是不出活，效果不好
  - 能力不错，但态度不好，经常抱怨，影响团队
  - 表现很好，超出预期，要给高绩效
  - 表现不合格，要给差评，甚至可能淘汰
  - 等等...]

请帮我准备完整的沟通方案：

一、沟通前准备
1. 我自己要先想清楚什么？
2. 哪些事实和数据我必须准备好？
3. 哪些话绝对不能说？
4. 我最担心的场景是什么？怎么应对？

二、沟通步骤和话术

开场怎么说：
- 怎么开场不尴尬？
- 怎么营造轻松但正式的氛围？
- 话术示例

先说优点和做得好的地方：
- 哪些优点一定要具体说，不要空泛？
- 怎么说能让他觉得你真的看到了他的努力？
- 话术示例

再说待改进的地方：
- 怎么说不好的地方，他更容易接受，不会抵触？
- 怎么对事不对人？
- 怎么用「观察到的事实 + 造成的影响 + 你的期望」这个结构？
- 话术示例，给几个不同说法的版本

听他的反馈和解释：
- 他可能会怎么辩解？怎么应对？
- 他要是情绪激动、哭了怎么办？
- 他要是不认可你的评价怎么办？
- 怎么提问，引导他自己意识到问题？

达成共识和行动方案：
- 怎么一起制定改进计划？
- 接下来 1-3 个月，具体要做什么？
- 你能提供什么支持和帮助？
- 怎么让他觉得这是我们一起解决的问题，不是你在针对他？

结尾怎么说：
- 怎么收尾，让他带着动力离开，而不是带着情绪？
- 怎么表达你对他的信心和期望？
- 话术示例

三、不同情况的应对方案

如果他情绪激动，很生气：
- 第一步怎么做？
- 怎么安抚情绪？
- 什么时候可以继续聊？什么时候应该终止谈话？

如果他不认可，一直辩解：
- 怎么说，既坚持你的观点，又不让他觉得你在针对他？
- 哪些时候可以妥协？哪些时候绝对不能让步？

如果他直接说要离职：
- 第一句怎么回应？
- 接下来怎么聊？
- 哪些话不能说？

如果他默默不说话，也不表态：
- 怎么引导他开口？
- 怎么判断他是听进去了，还是只是在应付？

四、避坑指南

绝对不能说的 10 句话：
1. ...
2. ...
这些话一说出口，关系就毁了，员工就记恨你了。

绝对不要做的 5 件事：
1. ...
2. ...

五、后续跟进
- 绩效沟通完，接下来的一周、一个月，应该怎么做？
- 怎么观察他有没有真的在改进？
- 怎么及时给予正反馈？
- 多久再做一次跟进沟通？
```

### 场景 4：员工关系和团队管理

#### 4.1 处理员工矛盾和冲突

```
你是一位经验丰富的 HRBP 和团队管理者，
处理过很多团队矛盾，特别会协调和沟通。

团队里有两个员工闹矛盾了，情况是：
[详细描述你知道的情况：
  - A 和 B 是谁，什么职位
  - 因为什么事情闹的矛盾
  - 现在发展到什么程度了
  - 对团队有什么影响
  - 你之前做了什么处理，效果怎么样]

请帮我制定完整的处理方案：

一、情况分析和判断
1. 这个矛盾的严重程度？（1-10 分）
2. 是工作上的分歧，还是个人恩怨？
3. 谁主要有责任？还是两个人都有问题？
4. 对团队的影响有多大？不处理会怎么样？
5. 有没有可能调和？还是必须有一个人走？

二、处理原则和底线
1. 哪些原则是必须坚持的？
2. 哪些情况是绝对不能容忍的？
3. 最坏的结果是什么？我能不能接受？
4. 我处理这个事情的目标是什么？

三、分别沟通的方案
先和 A 单独聊：
1. 怎么开场？
2. 问哪些问题？了解情况？
3. 怎么引导他说出真实的想法？
4. 怎么让他不要有抵触情绪？
5. 哪些话要问，哪些话不要问？
6. 聊完之后，我要确认哪些信息？

再和 B 单独聊：
- 同上

四、双方一起沟通的方案
什么时候需要把两个人拉到一起聊？
1. 怎么开场？
2. 怎么定沟通规则？（不许打断、不许人身攻击）
3. 怎么引导他们把话说开，不要翻旧账？
4. 怎么控制现场情绪，不要吵起来？
5. 吵起来了怎么拉架？
6. 怎么引导他们达成共识？
7. 最后怎么收尾？

五、不同结果的处理方案

如果和好了，问题解决了：
- 接下来怎么跟进？
- 怎么避免以后再发生？
- 怎么修复他们的关系？

如果没和好，但是能维持表面和平，不影响工作：
- 接下来怎么处理？
- 怎么减少他们的工作交集？
- 怎么安抚双方？

如果矛盾不可调和，必须走一个：
- 应该让谁走？为什么？
- 怎么和他谈离职？
- 怎么和团队其他人解释？
- 怎么避免影响团队士气？

六、后续跟进和团队修复
1. 事情处理完之后，接下来的一周、一个月要做什么？
2. 怎么观察团队的情绪变化？
3. 怎么避免其他团队成员站队？
4. 怎么重建团队信任？
5. 以后怎么预防类似的事情发生？
```

#### 4.2 离职谈话和劝退

```
你是一位处理过很多员工离职的资深 HR，
特别会做离职谈话，既能把事情办好，又能让员工体面离开，
不会让员工怀恨在心，也不会给公司留下法律风险。

我要和一个员工谈离职，情况是：
[详细描述情况：
  - 员工是谁，什么职位，做了多久
  - 为什么要让他走：绩效不好？裁员？还是其他原因？
  - 赔偿方案是什么？
  - 他的性格怎么样？可能会有什么反应？
  - 有没有什么历史问题？]

请帮我准备完整的离职谈话方案：

一、谈话前准备
1. 哪些材料必须准备好？（离职协议、赔偿计算、交接清单等）
2. 哪些法律风险要注意？
3. 哪些话绝对不能说？说了会有劳动仲裁风险？
4. 如果他录音了怎么办？哪些话就算被录下来也没问题？
5. 在哪里谈？谈多久？哪些人要在场？
6. 最坏的情况是什么？我能不能接受？怎么应对？

二、谈话步骤和话术

开场：怎么直接开门见山，不要绕弯子？
- 第一句话怎么说？
- 话术示例 1：直接但温和版本
- 话术示例 2：更直接、没有余地版本（给实在谈不拢的人）

说明决定和原因：
- 怎么说原因，既明确，又不侮辱人，不让他没面子？
- 哪些原因可以说，哪些原因绝对不能说？
- 怎么说，让他觉得这是一个基于事实的决定，不是你在针对他？
- 话术示例

说明赔偿和方案：
- 赔偿怎么计算的，一条一条说清楚
- 什么时候给钱，怎么给
- 社保公积金怎么处理
- 离职证明怎么开
- 哪些是可以商量的，哪些是没得商量的

听他的反应和诉求：
- 如果他情绪崩溃，哭了，怎么办？
- 如果他很生气，拍桌子，骂人，怎么办？
- 如果他不同意，要去仲裁，怎么办？
- 如果他要求更多赔偿，怎么办？什么情况可以加，什么情况绝对不能加？

谈交接和后续：
- 交接给谁？交接多久？
- 交接期间怎么算工资？
- 交接期间公司有什么义务？他有什么义务？
- 交接完怎么收尾？

收尾和送他离开：
- 最后怎么说？好聚好散？
- 要不要送他到公司门口？
- 以后还能不能联系？

三、常见问题和标准答案

员工问：「为什么是我？不是别人？」怎么答？
员工问：「是不是我哪里做得不好？」怎么答？
员工问：「能不能给我多一点时间找工作？」怎么答？
员工问：「离职证明会不会写不好的东西？」怎么答？
员工问：「我能不能和团队同事道别？」怎么答？
... 至少准备 10 个常见问题的答案，每个准备 2 个版本的说法。

四、法律风险和避坑指南

1. 哪些话一说出口，就会成为仲裁的证据？
2. 哪些行为绝对不能做？
3. 怎么确保整个过程合法合规，没有漏洞？
4. 万一真的仲裁了，我们有什么证据？
5. 哪些情况一定要请律师介入，不要自己谈？

五、后续处理

1. 谈完之后，怎么和团队其他成员说？
2. 怎么避免大家猜测和谣言？
3. 他的工作怎么交接给谁？怎么安排？
4. 怎么安抚团队其他成员的情绪？
5. 怎么从这次离职中吸取教训，以后避免类似情况？

最后，给一句最重要的忠告：做这个谈话，心态要稳，要有同理心，对方也是人，也需要体面。
```

## 真实案例

### 案例 1：用 AI 帮你改 JD，招聘效率提升一倍

**背景**：某创业公司 HR，招人总是招不到合适的，JD 投出去没人看，或者来的人都不对。

**AI 用法**：
1. 把原来的 JD 喂给 AI，让 AI 找问题
2. 告诉 AI 你真正想要什么样的人，让 AI 重写
3. 让 AI 写 3 个不同风格的版本，挑最好的
4. 让 AI 告诉你，这个职位的候选人会搜什么关键词，怎么优化 JD 的 SEO

**效果**：原来 JD 发出去一周收 10 份简历，现在一周收 50 份，而且质量明显更高，和职位的匹配度也好很多，面试通过率大大提升。

---

### 案例 2：不会和员工谈绩效？AI 当你的沟通教练

**背景**：某新主管，刚升上来，不会和员工做绩效沟通，要么太温和说不动人，要么太凶把员工说哭了，每次谈完反而效果更差。

**AI 用法**：
1. 把员工的情况和问题告诉 AI
2. 让 AI 帮你设计完整的沟通方案，每一句话怎么说都写好
3. 和 AI 角色扮演，模拟沟通，AI 当员工，你练习怎么说
4. 让 AI 指出你沟通中的问题，怎么改进
5. 谈完之后，把沟通情况告诉 AI，让 AI 帮你分析下一步怎么做

**效果**：原来谈完员工要么炸了，要么蔫了，现在谈完员工知道自己哪里有问题，也知道怎么改进，还会感谢你真诚的反馈，团队氛围也好很多。

## 注意事项

### ❌ 不要用 AI 代替你和员工的沟通和情感连接

HR 的工作，核心是和人打交道，是情感、是信任、是关系。

AI 可以帮你：
- 写沟通话术
- 给你建议
- 提醒你注意什么
- 帮你做准备

但是真正和员工坐下来聊天，听他说话，理解他的情绪，给他关怀，这些事情必须你自己做，AI 代替不了。

不要因为有了 AI，就变得更冰冷，更官僚。

---

### ❌ 不要让 AI 做人事决策！

要不要录用这个人？
要不要给这个人晋升？
要不要开除这个人？

这些决定，必须人来做。

AI 可以帮你整理信息，帮你列优缺点，帮你做风险评估，
但最终的决策，必须你来做，因为你要为这个决策负责，AI 不用负责。

---

### ❌ 绝对不要输入员工的敏感信息！

员工的个人信息、绩效信息、薪资信息、健康信息、家庭情况，这些都是高度敏感的。

**绝对不要**把这些信息粘贴到公有 AI 服务里！
轻则侵犯员工隐私，重则违法。

如果要用，一定要：
- 完全脱敏，去掉所有能识别出个人的信息
- 用公司内部部署的私有化 AI
