# 设计行业 AI 应用指南

适合：UI/UX 设计师、平面设计师、插画师、产品设计师、创意设计师

AI 正在深刻地改变设计行业，从创意生成、素材制作到细节优化，AI 都能帮上大忙。设计师不再需要花大量时间在重复性劳动上，可以更专注于创意本身。

---

## 这个行业可以用 AI 做什么

### 场景 1：创意生成和灵感探索

**适用人群**：所有需要创意的设计师

**能解决的问题**：
- 没灵感，脑子一片空白
- 想了很多方案都不满意
- 客户要「大气一点」「高端一点」，不知道是什么
- 想快速出多个方案对比

**具体用法**：

#### 1.1 创意脑暴和方向探索

```
你是一位资深的创意总监，有 15 年的品牌设计经验，
见过各种各样的设计风格，擅长从不同角度思考。

我们要做一个 [产品/品牌/海报/UI] 设计，
产品是：[描述产品，如：一个面向年轻人的咖啡品牌]
目标用户是：[谁，如：20-35 岁的都市白领]
想要传达的感觉是：[如：年轻、有活力、专业、可靠、温暖]

请帮我想 8 个完全不同的设计方向，每个方向都要有明显的差异化。

对每个方向，请说明：

1. 方向名称
   - 起个好听的名字，比如「极简科技风」「复古潮酷风」

2. 核心创意概念
   - 一句话说明这个方向的核心想法是什么
   - 为什么这个方向适合我们的产品和用户？

3. 视觉关键词（5-8 个）
   - 可以用来搜索参考图，或者给 AI 画图的关键词
   - 比如：高对比度、几何图形、渐变、3D 渲染、磨砂玻璃...

4. 配色建议
   - 主色 + 辅色
   - 可以用 hex 色号，或者描述颜色的感觉

5. 字体建议
   - 适合用什么类型的字体？
   - 衬线/无衬线？圆润/棱角？粗体/细体？

6. 参考案例
   - 有什么知名的品牌/设计是类似风格的？
   - 可以让设计师去搜来看感觉

7. 这个方向的优缺点
   - 适合什么场景？
   - 可能有什么问题？
   - 适用/不适用的情况

最后，给这 8 个方向打个分（1-10 分），并选出你最推荐的 3 个，说明理由。
```

---

#### 1.2 关键词优化（给 AI 画图用）

```
你是一位 Midjourney / Stable Diffusion 提示词专家，
特别擅长写能生成好图的关键词。

我想要画的是：[描述你想要的图，比如：一个咖啡品牌的海报]
我现在想到的关键词有：[把你想到的关键词列出来]

请帮我优化和扩展这些关键词：

1. 基础版提示词（10 个左右关键词）
   - 最核心的元素
   - 保证不出错，稳定能出大概的感觉

2. 详细版提示词（30-50 个关键词）
   - 更具体、更精准
   - 包含风格、光线、构图、材质、视角等
   - 出图质量更高

3. 「高级感」关键词
   - 加了之后能让图瞬间变高级、变贵的词
   - 比如：cinematic lighting, hyperrealistic, 8k 等

4. 不同风格变体
   - 同样的内容，用不同风格表现
   - 比如：摄影风、插画风、3D 风、极简风、手绘风

5. 负面提示词（Negative Prompt）
   - 哪些词要排除，避免出坏图
   - 比如：ugly, blurry, low quality 等

对每个版本，直接给出可以复制粘贴到 Midjourney 的完整提示词。

最后，给一些调参建议：--ar 比例用多少？--style 用什么？--q 质量设多少？
```

### 场景 2：平面设计和品牌设计

**适用人群**：平面设计师、品牌设计师

#### 2.1 Logo 创意和设计思路

```
你是一位品牌设计专家，设计过很多知名 Logo。

我们要做一个新品牌，品牌信息如下：
- 品牌名称：[名称]
- 英文名称（如果有）：[名称]
- 行业：[什么行业]
- 目标用户：[谁]
- 品牌调性：[比如：年轻、科技、温暖、高端]
- 核心价值：[品牌想传达什么]

请帮我想 6 个完全不同的 Logo 设计方向：

对每个方向：
1. 设计概念
   - 核心创意是什么？
   - 用了什么隐喻？
   - 为什么适合这个品牌？

2. 视觉描述
   - 大概长什么样？
   - 用什么元素？
   - 什么风格？

3. 配色建议
   - 主色是什么？
   - 为什么用这个颜色？
   - 颜色传达的感觉？

4. 字体建议
   - 字标用什么类型的字体？
   - 为什么？

5. 优缺点分析
   - 这个方向好在哪里？
   - 有什么风险/问题？
   - 什么情况下适合用？

6. 参考案例
   - 有什么知名品牌的 Logo 是类似思路？
   - 可以去搜来看感觉

最后，给每个方向打分（1-10 分），并给出推荐排序。
```

#### 2.2 海报/宣传图文案和排版

```
你是一位资深的美术指导，擅长海报和视觉设计。

我们要做一张 [海报 / 朋友圈图 / 公众号头图 /  Banner]，
信息如下：
- 主题：[是什么活动/产品]
- 核心信息：[最想让用户看到的一句话]
- 次要信息：[时间、地点、价格等]
- CTA（行动号召）：[按钮上写什么，如：立即购买]
- 品牌调性：[什么样的感觉]

请帮我做设计方案：

1. 5 个不同的排版布局方案
   - 标题放哪里？
   - 图片和文字怎么放？
   - 视觉重点在哪里？
   - 每个方案画个文字版的布局示意图（用文字描述）

2. 文案优化
   - 主标题怎么写更吸引人？给 3 个版本
   - 副标题怎么写？
   - 有没有什么金句可以加？

3. 视觉风格建议
   - 用什么色调？
   - 用什么样的图片/插画风格？
   - 有什么设计元素可以加？

4. 字体建议
   - 标题用什么字体？
   - 正文用什么字体？
   - 字体大小和层级关系？

5. 反面教材
   - 这个设计最容易犯的错误有哪些？
   - 千万不要怎么做？
```

### 场景 3：UI/UX 设计

**适用人群**：产品设计师、交互设计师

#### 3.1 产品功能和交互设计

```
你是一位资深的 UX 设计师，设计过很多用户过亿的产品。

我们要做一个功能：[描述这个功能是做什么的]
目标用户是：[谁]
用户的使用场景是：[什么时候会用这个功能]

请帮我做 UX 设计：

1. 用户故事和使用流程
   - 完整的用户路径是什么样的？
   - 从用户打开 App，到完成操作，一共几步？
   - 用流程图的方式列出来

2. 每个步骤的界面和交互
   - 第一步：界面上有什么？用户要做什么？
   - 第二步：界面上有什么？用户要做什么？
   - ...
   - 每个步骤的设计要点和注意事项

3. 异常情况和边缘 case
   - 网络出错了怎么办？
   - 用户输入的内容不对怎么办？
   - 用户中途退出了怎么办？
   - 还有哪些可能出问题的情况？怎么处理？

4. 常见问题和解答（FAQ）
   - 用户可能会有什么疑问？
   - 怎么在界面上解答，不用用户找客服？

5. 设计 3 个不同的交互方案
   - 方案 1：最简单、最常规的做法
   - 方案 2：更有新意、体验更好的做法
   - 方案 3：最保守、不容易出错的做法

6. 对每个方案做评估
   - 优点、缺点
   - 开发成本
   - 用户学习成本
   - 推荐用哪个？为什么？
```

---

#### 3.2 设计评审和改进建议

```
你是一位严格但友好的设计评审专家。

我刚做了一个 [页面 / App / 网站] 的设计，
想请你帮忙看看有什么可以改进的地方。

这个设计是做什么的：[描述]
目标用户是：[谁]

（如果可以的话，描述一下设计的大概样子，或者截个图，用有视觉能力的模型）

请从以下几个维度帮我评审：

1. 信息层级
   - 主次信息是不是分明？
   - 用户能不能一眼看到最重要的东西？
   - 有没有什么不重要的信息太显眼了？
   - 有没有什么重要信息被藏起来了？

2. 易用性和交互
   - 用起来顺不顺？
   - 每个按钮是不是一看就知道是干嘛的？
   - 有没有什么地方用户可能会点错？
   - 操作流程是不是够简单？

3. 视觉和审美
   - 好看吗？有没有廉价感？
   - 配色是不是和谐？
   - 字体、间距、对齐是不是舒服？
   - 视觉风格是不是统一？

4. 一致性
   - 和产品其他地方的设计是不是一致？
   - 同样的组件，用法是不是一样？
   - 有没有出现不一样的设计规范？

5.  accessibility（无障碍）
   - 颜色对比够不够？色弱/色盲能看清吗？
   - 字是不是太小了？
   - 按钮是不是够大，好点？

6. 细节问题
   - 有没有对齐问题？
   - 有没有错别字？
   - 图标是不是清晰？
   - 间距是不是一致？

对每个问题：
- 指出问题在哪里
- 说明为什么这是个问题
- 给出具体的改进建议
- 严重程度：严重 / 中等 / 建议优化

最后，给这个设计打个总分（1-10 分），并给出最重要的 3 个改进点。
```

### 场景 4：素材和插画生成

**适用人群**：所有需要配图、插画的设计师

#### 4.1 图标和插画生成

```
你是一位插画师和图标设计专家。

我需要一组 [图标 / 插画]，用在 [什么地方，如：App 空状态 / 官网 / PPT]。

主题是：[比如：404 页面、数据为空、成功状态、错误提示]
风格要求：[比如：MBE 风格 / 扁平插画 / 3D 图标 / 线性图标]
颜色要求：[主色是什么，配色范围]

请帮我：

1. 想 5 个不同的创意概念
   - 每个概念用一句话描述画什么
   - 为什么这个创意适合这个场景？

2. 对每个概念，写出 Midjourney / Stable Diffusion 提示词
   - 包含：内容、风格、颜色、细节、质量等
   - 可以直接复制粘贴使用

3. 手绘草稿描述（给 AI 画图的线稿提示）
   - 如果我要先画线稿，应该怎么画？
   - 大概的构图和元素位置

4. 一致性建议
   - 怎么保证一组图的风格是统一的？
   - 有哪些参数/关键词要固定？
   - 怎么微调，让每张图看起来像一家人？

5. 后期优化建议
   - AI 生成的图，可能有哪些问题？
   - 怎么在 Figma / Photoshop 里优化？
   - 怎么去掉多余的东西，调整颜色？
```

### 场景 5：设计文档和沟通

**适用人群**：所有需要和开发、产品、客户沟通的设计师

#### 5.1 写设计说明和走查文档

```
你是一位专业的设计师，擅长写清晰易懂的设计文档。

我刚做完一个 [功能 / 页面] 的设计，
需要写一份设计说明，给产品经理、开发同学、测试同学看。

请帮我写一份完整的设计走查文档：

1. 设计概述
   - 这个设计是做什么的？
   - 解决了什么问题？
   - 设计目标是什么？

2. 页面和流程
   - 完整的用户流程图
   - 每个状态的截图/设计稿

3. 交互说明
   - 每个按钮点了之后会发生什么？
   - 正常流程是怎样的？
   - 异常情况（网络错、输入错）是怎样的？
   - 动效是怎样的？（时长、缓动函数）

4. 组件和规范
   - 用了哪些组件？
   - 哪些是新组件？新组件的规范是什么？
   - 间距、字号、颜色对应的 token 是什么？

5. 适配说明
   - 不同屏幕尺寸怎么适配？
   - 手机横屏/竖屏怎么处理？
   - 极端情况（文字特别长/特别短）怎么处理？

6. 可访问性（Accessibility）说明
   - 颜色对比度够不够？
   - 屏幕阅读器能读吗？
   - 键盘能不能操作？

7. 测试重点
   - 测试的时候要重点测哪些地方？
   - 有哪些容易出 bug 的地方？

8. 常见问题 QA
   - 开发可能会问什么问题？
   - 提前准备好答案

要求：
- 清晰、有条理
- 不要有歧义
- 开发看完就能照着做，不用再跑来问你
```

#### 5.2 和客户/需求方沟通话术

```
你是一位经验丰富的设计师，很会和客户沟通。

客户/产品经理对你说：
[客户的原话，比如：「我觉得这个设计不够大气」「感觉差点意思」「再改改」]

我听了有点懵，不知道具体要改什么。

请帮我分析和准备沟通的话术：

1. 客户这句话背后可能是什么意思？
   - 列出 3-5 种可能的理解
   - 每种可能性对应要改什么？

2. 怎么追问才能问清楚具体需求？
   - 不能直接说「你说清楚点」，会得罪人
   - 要有技巧地问，让客户说出具体的问题
   - 给 3 个不同的提问方式，适用于不同的客户关系

3. 怎么引导客户给出具体的反馈？
   - 而不是说「感觉不对」这种虚的话
   - 可以问哪些具体的问题？
   - 怎么让客户从「我要大气」变成「我想要这个蓝色再深一点，字再粗一号」

4. 如果客户的要求很离谱，怎么优雅地拒绝？
   - 既不答应不合理的要求，也不吵架
   - 还能让客户觉得你很专业
   - 给 2 个版本的话术（强硬一点 / 委婉一点）

5. 改完之后怎么发给客户，引导他给出好的反馈？
   - 怎么说，客户才会给具体的反馈，而不是「再改改」
   - 话术示例
```

## 真实案例

### 案例 1：用 AI 出 10 个方案，选一个再细化

**背景**：某 UI 设计师，做一个新功能的页面设计，想了好几个方案都不满意，卡住了。

**AI 用法**：
1. 把需求告诉 AI，让 AI 想 10 个完全不同的设计方向
2. 从 10 个里面挑 3 个有点意思的
3. 让 AI 详细展开这 3 个方向的具体设计
4. 再把这 3 个方案的优点结合起来，做自己的最终方案

**效果**：原来卡了一天，现在 1 小时就有思路了，而且方案比自己想的还丰富。

---

### 案例 2：用 AI 生成插画，省了买素材的钱

**背景**：某运营设计，做活动页需要很多插画，买素材要花不少钱，自己画又太慢。

**AI 用法**：
1. 先想好要什么风格的插画，找好参考图
2. 写好提示词，用 Midjourney 生成一批图
3. 挑几张好的，在 Figma 里简单修一下（改颜色、去背景）
4. 用到设计里

**效果**：原来买一套插画要几百上千元，现在花几块钱电费，1 小时就能搞定，风格还完全匹配，不会和别人撞图。

## 注意事项

### ❌ AI 生成的图可能有版权风险，商用要谨慎

现在 AI 画图的版权问题还没有完全明确：
- AI 生成的图算不算原创？
- 训练数据用了有版权的图，算侵权吗？
- 你用 AI 生成的图，版权属于你吗？

不同国家、不同公司的规定都不一样。

**建议**：
- 重要的、商用的 Logo，最好不要完全用 AI 生成的，自己再改改
- 甲方的项目，提前和客户说好有没有用 AI
- 核心的品牌资产，还是要设计师原创，更稳妥

---

### ❌ AI 经常会画错细节，一定要人工检查

AI 生成的图经常有这些问题：
- 手画得特别奇怪（六根手指、手指扭曲）
- 文字是乱码，像外星文
- 细节逻辑不对（比如：杯子的把手方向反了）
- 透视有问题
- 边缘有奇怪的噪点和 artifacts

**一定要仔细检查！不要直接用！**
后期花 5 分钟修一下，效果会好很多。

---

### ❌ 不要让 AI 代替你的思考和审美

AI 可以帮你：
- 快速出很多方案，给你灵感
- 生成素材，节省时间
- 做重复性的劳动

但是：
- 什么是好的设计，什么是坏的，需要你判断
- 方案怎么选，怎么结合，需要你决策
- 品牌的调性、设计的灵魂，需要你注入

AI 是你的助手，不是你的设计师。
你的审美、你的判断、你的创意，才是最有价值的。

---

### ❌ 不要只看「好不好看」，忘了设计的目的

很多设计师用 AI 生成了特别好看的图，但用到产品里发现不对：
- 好看是好看，但用户看不清文字
- 太花哨了，干扰了用户操作
- 和品牌整体风格不搭

记住：设计是为了解决问题的，不是为了好看而好看。
再好看的设计，如果解决不了问题，就不是好设计。

## 给设计师的心里话

很多设计师担心 AI 会取代自己，但其实：

**AI 不会取代设计师，但会用 AI 的设计师会取代不会用 AI 的设计师。**

以前的设计师，大量时间花在：
- 找参考
- 画第一版草图
- 做重复性的体力活
- 改 10 版方案，客户选了第 1 版

现在这些事情 AI 都能帮你快速完成。
你可以把时间花在更有价值的事情上：
- 理解用户需求
- 深入思考问题的本质
- 更好的创意和策略
- 更好的沟通和协调

拥抱 AI，把它变成你的超能力吧！🚀
