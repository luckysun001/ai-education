# 市场营销 AI 应用指南

适合：营销人、运营、新媒体、文案、品牌、增长黑客

AI 可以帮助市场营销人员提升效率、产出更多创意、实现数据驱动决策。

---

## 这个行业可以用 AI 做什么

### 场景 1：文案写作

**适用人群**：文案、新媒体、内容运营

**能解决的问题**：
- 写不出东西，脑子一片空白
- 写得太慢，赶不上热点
- 风格单一，想尝试不同文风
- 不同平台需要不同风格的文案

**具体用法**：

#### 1.1 公众号/长文章

```
你是一位资深的公众号小编，擅长写 [目标人群，如：职场年轻人] 喜欢看的文章。

我想写一篇关于 [主题] 的公众号文章，
文章的核心观点是：[你的观点]
目标读者是：[谁]
期望读者读完后的反应是：[转发 / 收藏 / 下单]

请帮我写：

1. 5 个备选标题（要吸引人，有点击欲）
2. 完整的文章大纲，分几个部分
3. 文章的开头和结尾（开头要吸引人，结尾要引导互动）
4. 文中可以加入的 3 个金句

风格要求：
- 语气：[亲切 / 专业 / 幽默 / 治愈]
- 字数：约 [2000] 字
- 要有案例/数据支撑，不要空讲道理
- 适当加一些 emoji
```

---

#### 1.2 小红书文案

```
你是一位小红书爆款文案写手，
擅长写能戳中 [目标人群，如：25-35 岁女生] 的种草文案。

请帮我写一篇关于 [产品/主题] 的小红书文案：

产品/内容的核心卖点：
1. [卖点 1]
2. [卖点 2]
3. [卖点 3]

目标人群：[谁]
使用场景：[什么时候用]

要求：
1. 标题要抓眼球，带情绪/数字/反差感
2. 开头第一句就要戳中痛点
3. 正文分点，每点不要太长
4. 多用口语化的表达，像和闺蜜聊天
5. 适当加入一些小红书常用词（谁懂啊、绝了、yyds、宝藏、踩坑...）
6. 加合适的 emoji
7. 最后加 5-8 个相关的 Hashtag

字数：控制在 300-500 字
```

---

#### 1.3 短视频脚本/文案

```
你是一位短视频内容策划，做过很多 100w+ 播放的爆款视频。

请帮我写一个 [15 秒 / 30 秒 / 1 分钟] 的短视频脚本，
主题是：[主题]
目标受众：[谁]
视频风格：[口播 / 剧情 / 开箱 / 测评]

请按以下格式输出：

## 核心钩子（前 3 秒必须抓住人）
[第一句话/第一个画面是什么]

## 完整脚本（画面 + 台词）
0-3 秒：画面 / 台词
3-10 秒：画面 / 台词
10-20 秒：画面 / 台词
...

## 字幕重点
哪些词要加粗/标红，突出显示

## BGM 建议
推荐什么风格的背景音乐

## 结尾引导
怎么引导点赞/关注/评论/转发

如果是带货视频，还要加入：
- 什么时候露出产品？
- 下单引导怎么说？
```

### 场景 2：内容策划和选题

**适用人群**：内容运营、新媒体主编

**能解决的问题**：
- 不知道写什么选题
- 追热点慢半拍
- 内容没有体系，想到啥写啥

**具体用法**：

```
你是一位资深的内容策划总监。

我们的账号是做 [领域，如：职场成长] 的，
目标用户是：[谁，如：工作 3-5 年的互联网人]
账号的定位是：[专业干货 / 情感共鸣 / 有趣好玩]

最近的热点有：
1. [热点 1]
2. [热点 2]
...

请帮我策划下周的内容选题：

1. 热点借势选题（3 个）
   - 结合最近的热点
   - 怎么和我们的定位结合？
   - 角度要新颖，不要蹭得太硬

2. 常规干货选题（5 个）
   - 用户最关心的问题
   - 最好是「反常识」的角度
   - 每个选题写 3 个备选标题

3. 互动/讨论选题（2 个）
   - 能引发用户评论、站队的选题
   - 争议性话题，但不要太敏感

4. 内容形式建议
   - 哪些适合做图文？
   - 哪些适合做视频？
   - 哪些适合做互动/投票？

对每个选题，请评估：
- 火爆概率（1-10 分）
- 制作难度（1-10 分）
- 互动潜力（1-10 分）
```

### 场景 3：用户洞察和数据分析

**适用人群**：数据运营、用户研究、品牌经理

**能解决的问题**：
- 看了很多数据，不知道意味着什么
- 用户评论太多，看不过来
- 不知道用户到底在想什么

**具体用法**：

#### 3.1 评论/用户反馈分析

```
你是一位用户研究专家。

以下是我们产品最近的 [100 条用户评论/反馈]：

[粘贴评论内容，或者总结一下主要内容]

请帮我做全面的分析：

1. 用户情绪概览
   - 正面/中性/负面的比例大概是多少？
   - 总体满意度怎么样？

2. 用户表扬最多的点（Top 5）
   - 按提及次数排序
   - 引用代表性的原话

3. 用户吐槽最多的点（Top 5）
   - 按提及次数排序
   - 问题的严重程度
   - 用户的核心诉求是什么？

4. 用户的新需求/建议（Top 5）
   - 用户想要什么我们现在没有的功能？
   - 哪些需求比较集中？

5. 典型用户画像
   - 从评论看，用我们产品的都是什么人？
   - 他们在什么场景下用？

6. 行动建议
   - 马上要改的（1 周内）
   - 中期要规划的（1-3 个月）
   - 长期要考虑的（半年以上）
```

---

#### 3.2 营销活动复盘分析

```
你是一位增长专家。

我们刚做完一个 [活动名称] 活动，数据如下：

[列出来核心数据，如：
- 曝光：xxx
- 点击：xxx
- 转化率：x%
- 新增用户：xxx
- 付费用户：xxx
- ROI：1:x
]

历史同期数据是：[可以对比]

请帮我做复盘分析：

1. 这次活动做得好的地方（至少 3 点）
   - 数据支撑
   - 为什么做得好？

2. 做得不好的地方（至少 3 点）
   - 数据支撑
   - 可能的原因是什么？

3. 有没有什么异常的点？
   - 哪个环节数据特别好/特别差？
   - 可能是什么原因？

4. 用户反馈怎么样？
   - 用户喜欢什么？
   - 用户吐槽什么？

5. 下次怎么改进？
   - 策略层面的建议
   - 执行层面的建议
   - 可以沉淀下来的 SOP
```

### 场景 4：竞品分析和市场研究

**适用人群**：品牌经理、市场研究、战略

```
你是一位市场研究专家。

我们的品牌是：[你的品牌]
我们的主要竞品是：[竞品 A]、[竞品 B]

最近我们发现 [某个变化，比如：竞品销量大涨 / 竞品做了个 campaign]

请帮我分析：

1. 竞品的策略是什么？
   - 他们想做什么？
   - 目标用户是谁？
   - 核心卖点是什么？
   - 用了什么渠道？

2. 他们做得好的地方
   - 哪些地方值得我们学习？
   - 为什么这个点有效？

3. 他们做得不好的地方
   - 哪些地方我们可以差异化？
   - 用户吐槽他们什么？

4. 用户怎么看我们 vs 竞品？
   - 用户选择他们而不是我们的原因？
   - 用户选择我们而不是他们的原因？

5. 我们接下来可以怎么做？
   - 短期应对（1 个月内）
   - 中期策略（3-6 个月）
   - 不要硬碰硬，找差异化机会
```

### 场景 5：海报/视觉创意辅助

**适用人群**：设计师、运营（自己做图）

AI 虽然不能直接帮你做完美的图，但可以帮你：
- 找灵感、出创意
- 生成素材图
- 写文案配文
- 改文案、改 slogan

```
你是一位创意总监。

我们要做一张 [海报 / 朋友圈图 / 宣传图]，
主题是：[主题]
目的是：[宣传新品 / 活动预热 / 品牌曝光]
目标受众是：[谁]

请帮我出 5 个完全不同风格的创意方案：

方案 1：[风格名称，如：极简科技风]
- 核心视觉：画面上有什么？
- 配色建议：主色+辅色
- 排版建议：字怎么放？
- 文案：主标题 + 副标题
- 适合什么渠道：朋友圈 / 公众号头图 / 海报？

方案 2：...

对每个方案，给出一个「惊艳程度」评分和「制作难度」评分。

最后，给出如果用 AI 画图（Midjourney / DALL-E），每个方案的关键词提示词。
```

## 真实案例

### 案例 1：用 AI 写文案，产出提升 3 倍

**背景**：某新媒体小编，一天要写 3 篇公众号+5 条小红书，写不出来。

**AI 用法**：
1. 先用 AI 出 10 个选题，挑 3 个
2. 每个选题让 AI 出 5 个标题，选 1 个
3. AI 写大纲，自己调整
4. AI 写初稿，自己改细节、加个人案例
5. 最后让 AI 帮忙润色、加金句

**效果**：原来一天写 1-2 篇，现在一天写 4-5 篇，质量还更好。

**心得**：AI 写 80 分的初稿，人来做最后 20 分的优化和风格化。

---

### 案例 2：用 AI 分析 1000 条用户评论

**背景**：某品牌做了一次大促，收到 1000 多条用户评论，看不过来。

**AI 用法**：
1. 把所有评论喂给 AI（用长上下文的模型，比如 Claude）
2. 让 AI 分类、总结、提取关键词
3. 让 AI 找出提得最多的问题
4. 让 AI 给出改进建议

**效果**：原来要花 3 天看的评论，1 小时就分析完了，还发现了几个之前没注意到的共性问题。

## 注意事项

### ❌ 不要直接复制粘贴就发

AI 写的文案往往：
- 太「正确」，没有个人风格
- 容易空洞，缺少真实案例
- 有时候会瞎编数据

**正确做法**：
- AI 写初稿，你要改
- 加入自己的真实经历、感受、案例
- 调整成你自己的说话风格
- 重要的事实、数据一定要核实

---

### ❌ 不要所有内容都让 AI 写

你的个人体验、个人故事、独特观点，这些是 AI 写不出来的，也是你的内容最有价值的地方。

AI 帮你写：框架、常规内容、不同版本的尝试
你来写：个人故事、真实案例、核心观点、情感表达

---

### ❌ 不要只看表面数据

AI 可以帮你分析数据，但你要理解业务背景。
AI 说「这个转化率低」，但为什么低？是渠道问题？还是产品问题？还是价格问题？
这些需要你结合业务去判断。
