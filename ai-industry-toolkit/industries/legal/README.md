# 法律行业 AI 应用指南

适合：律师、法务、法官、法学研究者、法学生

AI 正在改变法律服务行业，从法律检索、合同审查到法律文书写作，都能大幅提升效率。

---

## ⚠️ 重要免责声明

**本指南仅用于提升工作效率和辅助学习，不能替代专业法律意见。**

1. AI 不能执业，不能代替律师
2. AI 输出的法律内容可能有错误，必须由专业律师核对
3. 涉及客户隐私和案件保密的信息绝对不能输入公有 AI 服务
4. 重要法律决策必须由专业法律人士做出

---

## 这个行业可以用 AI 做什么

### 场景 1：法律检索和研究

**适用人群**：所有法律从业者

**能解决的问题**：
- 法条太多，找起来麻烦
- 案例太多，读不过来
- 某个法律问题不知道怎么入手
- 想快速了解某个领域的法律框架

**具体用法**：

#### 1.1 法律问题调研和框架梳理

```
你是一位资深的 [民商事 / 刑事 / 知识产权] 律师，
有 15 年的执业经验，对中国法律体系非常熟悉。

我遇到了一个法律问题：[详细描述你的法律问题，包括背景]

请帮我做全面的法律调研和分析：

一、这个问题涉及哪些法律领域？
   - 可能涉及哪些部门法？
   - 核心的法律关系是什么？

二、相关的法律法规和司法解释
1. 最核心的法律条文有哪些？（至少 5-10 条）
   - 列出法条编号和名称
   - 简单说明每条和这个问题的关系
2. 有没有相关的司法解释？
3. 有没有行政法规、部门规章？
4. 有没有地方性的规定？

三、司法观点和裁判倾向
1. 最高院有没有相关的指导案例、公报案例？
2. 最高院有没有相关的会议纪要、答复、意见？
3. 目前司法实践中的主流观点是什么？
4. 有没有什么争议点？不同法院会不会判得不一样？

四、学术观点和理论争议
1. 学界对这个问题有什么不同看法？
2. 主流观点是什么？少数观点是什么？
3. 有没有知名学者的著述可以参考？

五、检索关键词建议
   - 如果我要去威科先行、裁判文书网搜，应该用什么关键词组合？
   - 至少给 5 组不同的关键词
   - 哪些关键词是必须的？哪些可以扩大范围？

六、相关的案例类型
   - 这类案件一般是什么案由？
   - 常见的争议焦点有哪些？
   - 原告一般诉什么？被告一般怎么抗辩？

七、风险和注意事项
   - 这个问题上，最容易踩什么坑？
   - 有哪些常见的错误认识？

最后，给一个进一步研究的路线图：
- 第一步应该看什么？
- 第二步应该看什么？
- 有哪些核心的资料一定要读？
```

---

#### 1.2 判决书/案例速读和要点提取

```
你是一位经验丰富的律师，擅长从复杂的判决书中快速提炼要点。

这是一份判决书/裁定书：

[粘贴判决书全文或者核心部分]

请帮我做案例分析和摘要：

一、案件基本信息
1. 案号、审理法院、审理程序
2. 当事人是谁？
3. 案由是什么？
4. 判决结果是什么？（谁赢了？赔了多少？）

二、案件事实
   - 用自己的话，把案件事实说清楚
   - 不要太啰嗦，讲清楚来龙去脉就行
   - 重点讲和判决相关的关键事实

三、双方的诉辩主张
1. 原告/上诉人说什么？主张是什么？证据是什么？
2. 被告/被上诉人说什么？抗辩是什么？证据是什么？
3. 双方争议的焦点是什么？

四、法院的裁判理由
1. 法院对事实是怎么认定的？
2. 法院适用了什么法律？
3. 为什么这么判？核心逻辑是什么？
4. 对双方的主张，法院哪些支持了，哪些没支持？为什么？

五、这个案子的关键裁判要点
1. 这个判决最核心的裁判规则是什么？
2. 哪些法律要点得到了明确？
3. 这个判决有什么指导意义？

六、对我们的启示
1. 如果我们是胜诉方，这个判决哪些地方值得参考？
2. 如果我们是败诉方，输在哪里？下次怎么避免？
3. 这个判决有没有什么风险点？有没有上诉的机会？

最后，用 3 句话总结这个案子最核心的信息。
```

#### 1.3 多个案例的对比和裁判观点总结

```
你是一位法律案例研究专家。

我搜了一批关于 [某个法律问题] 的案例，大概有 10-20 个。

这些案例的判决要点分别是：
[把每个案例的核心要点列出来，或者直接把所有判决喂给 AI]

请帮我做对比和总结：

一、这些案例的共同点是什么？
1. 法院一般会支持什么？不支持什么？
2. 认定事实的标准是什么？
3. 适用法律的标准是什么？

二、这些案例有什么不同和分歧？
1. 哪些地方不同法院判得不一样？
2. 为什么会有分歧？是事实不同？还是法律理解不同？
3. 有没有明显的地域差异？级别差异？

三、影响判决结果的关键因素
   - 哪些事实，出现了大概率会赢？
   - 哪些事实，出现了大概率会输？
   - 法官最看重什么？
   - 律师的哪些抗辩点最容易被采纳？

四、裁判观点的时间变化趋势
   - 早年怎么判？近年怎么判？
   - 有没有什么变化？是越来越严还是越来越松？
   - 最新的判例倾向是什么？

五、对我们的策略建议
   - 以后碰到类似的案子，应该怎么准备？
   - 重点准备哪些证据？
   - 哪些抗辩点是有效的？哪些是没用的？
   - 哪些点要重点和法官说？

六、风险提示
   - 哪些点目前司法实践中还有争议？
   - 哪些点法院支持率不高，不要抱太大希望？
   - 有什么最新的案例改变了之前的裁判规则？
```

### 场景 2：合同审查和起草

**适用人群**：律师、法务

#### 2.1 合同审查和风险点排查

```
你是一位资深的公司合规律师，
审查过成千上万份合同，火眼金睛，特别擅长找坑。

这是一份 [什么类型的合同，如：采购合同 / 服务合同 / 保密协议]，
我们是 [甲方 / 乙方]。

合同内容如下：
[粘贴合同全文]

请帮我做全面的合同审查：

一、整体评价
1. 这份合同整体怎么样？公平吗？
2. 对我们有利还是不利？有利/不利程度打个分（1-10 分）
3. 整体风险大不大？

二、条款缺失检查
   - 一份正常的这类合同，应该有哪些必备条款？
   - 这份合同缺了哪些重要条款？
   - 每个缺失的条款，会有什么风险？
   - 应该怎么补上？

三、风险点和坑点排查（逐条说）

按风险等级分类：

🔴 高风险（必须改，不然会出大事）：
1. 第 X 条，内容是 ...
   - 问题是什么？
   - 最坏会怎么样？
   - 修改建议是什么？
   - 如果对方不肯改，有什么替代方案？

🟡 中风险（最好改，不然可能有麻烦）：
1. 第 X 条，内容是 ...
   - 问题是什么？
   - 修改建议是什么？

🟢 低风险 / 建议优化：
1. 第 X 条，内容是 ...
   - 为什么建议改？
   - 怎么改更好？

四、不公平条款和霸王条款
   - 哪些条款明显对我们不利，权利义务不对等？
   - 哪些是对方埋的坑？
   - 这些条款的法律效力怎么样？会不会被认定为无效？
   - 我们应该怎么谈？哪些一定要改，哪些可以妥协？

五、违约责任分析
1. 我们违约，责任有多重？有没有太重？
2. 对方违约，责任有多重？有没有太轻？
3. 违约责任公平吗？对等吗？
4. 有没有什么情况我们会莫名其妙违约？

六、争议解决条款分析
   - 管辖法院约定合理吗？对我们有利还是不利？
   - 仲裁还是诉讼？哪个对我们更好？
   - 有没有约定无效的可能？

七、其他需要注意的问题
   - 有没有什么隐藏的义务？
   - 有没有什么我们签了字，要承担责任，但我们没注意到的？
   - 有没有什么表述模糊，以后可能会有争议的地方？

八、最终建议
   - 这份合同，总体我们能不能签？
   - 哪些是谈判的时候必须争取改的？
   - 哪些是可以让步的？
   - 签了之后执行过程中要注意什么？
```

#### 2.2 合同起草和模板制作

```
你是一位资深的 [行业] 法律专家，
擅长起草严谨、实用、少踩坑的合同模板。

我需要起草一份 [什么类型的合同]，
合同双方是：[甲方是谁 / 乙方是谁]
交易的核心内容是：[简单说一下交易是什么]

我们的立场和核心诉求是：
[说明我们最在意什么，最想保护什么，最担心什么风险]

请帮我起草这份合同：

一、合同整体框架和结构
   - 这份合同应该分几个部分？
   - 每个部分写什么内容？
   - 逻辑顺序怎么安排？

二、核心条款设计
1. 核心权利义务条款
   - 甲方应该做什么？做到什么标准？
   - 乙方应该做什么？做到什么标准？
   - 验收标准是什么？怎么验收？验收不通过怎么办？

2. 付款条款
   - 付款时间？付款条件？
   - 付款到哪里？
   - 发票怎么开？什么时候开？
   - 不按时付款的违约责任？

3. 违约责任条款
   - 各种违约情况怎么处理？
   - 违约金怎么约定合理，又能有威慑力？
   - 哪些情况可以解除合同？
   - 损失怎么赔偿？哪些损失赔，哪些不赔？

4. 保密条款
   - 哪些信息要保密？
   - 保密多久？
   - 泄密了怎么办？

5. 知识产权条款
   - 合作过程中产生的知识产权归谁？
   - 双方怎么使用？
   - 侵权了怎么办？

6. 争议解决条款
   - 选仲裁还是诉讼？
   - 选哪个法院/仲裁委？为什么？
   - 法律适用？

7. 其他必备条款
   - 不可抗力
   - 通知和送达
   - 合同生效和期限
   - 合同变更和解除
   - 等等...

三、保护我们利益的特殊条款
   - 针对我们最担心的风险，专门设计的条款
   - 哪些地方要写得对我们更有利？
   - 哪些地方要提前把坑填上？

四、给对方挖坑的条款要不要？
   - 哪些是行业常规操作？
   - 哪些太过分，对方肯定不同意？
   - 哪些可以写进去，作为谈判的筹码？

五、谈判策略建议
   - 哪些条款是我们绝对不能让的？
   - 哪些条款是可以用来交换的？
   - 对方大概率会在哪些地方讨价还价？
   - 我们应该怎么应对？

最后，给一份完整的合同初稿，我可以直接拿去用和修改。
```

### 场景 3：法律文书写作

**适用人群**：律师、法务

#### 3.1 起诉状/答辩状/上诉状写作

```
你是一位经验丰富的诉讼律师，
写过很多文书，很会抓重点，讲道理。

我要写一份 [起诉状 / 答辩状 / 上诉状]，
案件情况是：[详细描述案件背景、事实、证据]

我们的立场是：[原告 / 被告 / 上诉人 / 被上诉人]
我们的核心诉求是：[我们想要什么结果]

请帮我起草这份文书：

一、文书整体框架和思路
1. 整体的诉讼策略是什么？
2. 我们最核心的论点有几个？按重要性排序？
3. 哪些点要重点说，哪些点可以一笔带过？
4. 哪些点最好不说，避免自曝其短？

二、事实陈述部分
1. 事实怎么组织？按什么顺序说？
2. 哪些事实要突出强调？
3. 哪些事实要淡化处理？
4. 怎么说显得客观可信，不像在编故事？
5. 哪些事实最好不要写，留给开庭再说？

三、法律论证部分
1. 第一个论点：
   - 我们的主张是什么？
   - 法律依据是什么？
   - 事实依据是什么？
   - 怎么论证最有说服力？

2. 第二个论点：
   ...

（每个论点都按这个结构写）

四、针对对方可能的抗辩，提前预判和回应
   - 对方大概率会怎么抗辩？
   - 我们要不要在文书里提前回应？
   - 怎么回应？

五、诉讼请求设计
1. 诉讼请求怎么写？有没有遗漏？
2. 哪些请求法院大概率会支持？哪些可能不支持？
3. 有没有什么请求是写法不对，会直接被驳回的？
4. 违约金、利息、律师费这些怎么算怎么写？

六、证据清单和举证思路
1. 哪些证据是必须的？
2. 哪些证据是补强的？
3. 证据怎么排序？怎么组织？
4. 每一份证据要证明什么？
5. 哪些证据最好不要提交？

七、注意事项和避坑指南
1. 写这类文书最容易犯的错误有哪些？
2. 哪些话绝对不能写？
3. 法官看这类文书，最看重什么？最烦什么？
4. 怎么写能让法官看着舒服，更容易采纳你的观点？

最后，给一份完整的文书初稿。注意语言要专业、简洁、有逻辑，不要情绪化。
```

#### 3.2 法律意见书/律师函写作

```
你是一位资深的非诉律师，擅长写专业、严谨、有说服力的法律意见书。

我要写一份 [法律意见书 / 律师函]，
背景情况是：[描述背景]
收函方/咨询方是：[谁]
我们的目的是：[想要达到什么效果]

请帮我起草：

一、整体定位和语气把握
1. 这份文件的目的是什么？是警告？是告知？是协商？是施压？
2. 语气应该怎么样？强硬？温和？还是不卑不亢？
3. 哪些话该说，哪些话不该说？
4. 怎么说既能达到目的，又不把话说死，留有余地？

二、法律意见书结构
1. 抬头和引言
2. 背景事实陈述
   - 怎么客观中立地陈述事实？
   - 哪些事实要写，哪些不要写？
3. 法律分析部分
   - 分点论述
   - 法律依据 + 事实对应
   - 结论是什么
4. 法律意见和建议
   - 明确给出结论
   - 建议怎么做，分几步做
   - 每种方案的风险和利弊
5. 风险提示和免责声明
   - 哪些情况我们不承担责任？
   - 怎么保护自己？

三、律师函结构和要点
1. 标题怎么写？要不要写「律师函」三个大字？
2. 开场白怎么说？
3. 事实陈述部分，怎么写对我们有利？
4. 法律分析部分，怎么说既专业又有威慑力？
5. 要求部分：要求对方做什么？多久做？不做会怎么样？
6. 结尾怎么说？既施压又留有余地？

四、避坑指南
1. 写法律意见书/律师函最容易犯什么错误？
2. 哪些话写了会给自己和客户带来麻烦？
3. 哪些承诺绝对不能做？
4. 免责声明怎么写才有效？
5. 万一写错了，有什么补救措施？

最后，给一份完整的文书初稿。
```

### 场景 4：法律学习和考试

**适用人群**：法学生、实习律师、准备司考/法考的人

#### 4.1 法律知识点梳理和记忆

```
你是一位法学教授，同时也是法考辅导专家，
特别擅长把复杂的法律知识讲得简单明白，好记。

我现在在学 [某个部门法，如：民法 / 刑法 / 民诉]，
正在学 [某个具体知识点，如：善意取得 / 犯罪未遂]。

请帮我梳理这个知识点：

1. 基础概念
   - 用最简单的话解释，这个东西到底是什么？
   - 用生活中的例子打个比方
   - 它为什么会存在？立法目的是什么？要解决什么问题？

2. 构成要件/成立条件
   - 几个要件？分别是什么？
   - 每个要件怎么理解？
   - 缺一个会怎么样？
   - 有没有什么例外情况？

3. 法律效果/后果
   - 成立了会怎么样？
   - 不成立会怎么样？
   - 有什么法律效力？

4. 对比和鉴别
   - 这个和那个很像的概念有什么区别？
   - 比如：善意取得 vs 无权处分，未遂 vs 中止
   - 列个表格对比，一眼就能看明白

5. 常见的坑和易混淆点
   - 大家最容易理解错的地方有哪些？
   - 法考最常考的陷阱是什么？
   - 至少列 5-10 个

6. 记忆口诀和技巧
   - 有没有什么好记的口诀？
   - 有没有什么联想记忆的方法？
   - 怎么记不容易忘？

7. 经典案例和真题
   - 这个知识点最经典的案例是什么？

8. 知识体系和关联
   - 这个知识点在整个部门法里的位置是什么？
```

## 真实案例

### 案例 1：用 AI 审合同，一小时顶一天

**背景**：某公司法务，经常要审各种合同，工作量很大，特别是标准版本的合同，重复劳动很多。

**AI 用法**：
1. 把合同喂给 AI，让它先做第一遍审查
2. AI 把所有风险点列出来，按严重程度分类
3. 法务自己再看一遍，重点看 AI 标出来的高风险点
4. 让 AI 把修改建议直接写成条款，复制粘贴就能用

**效果**：原来审一份合同要 1-2 小时，现在 15-30 分钟就能审完，而且还不容易漏，因为 AI 看得比人仔细，不会漏条款。省出来的时间可以做更有价值的法律研究和策略制定。

---

### 案例 2：用 AI 做类案检索，找上诉思路

**背景**：某诉讼律师，一审输了，想上诉，但不知道从哪里找突破口，判决书写得好像挺有道理的。

**AI 用法**：
1. 把一审判决书喂给 AI，让它找判决书中可能有问题的地方
2. 把这些争议点列出来，让 AI 去搜类似的案例，看看有没有其他法院是怎么判的
3. 找 10-20 个类似案例，让 AI 总结哪些上诉理由成功率高
4. 结合自己的案子，选 3 个最有力的上诉理由

**效果**：原来要花好几天搜案例、读案例，现在半天就搞定了，而且还找到了几个自己没想到的上诉角度，上诉状写得有理有据，最后二审发回重审了。

## ⚠️ 最重要的注意事项

### 1. 绝对不能用 AI 代替律师做法律判断！

再强调一遍：
- AI 说这个案子能赢，不一定能赢
- AI 说这个条款没问题，不一定没问题
- AI 引用的法条，可能是旧的、废止的
- AI 说的案例，可能根本不存在

**所有法律意见，必须由律师自己做出！**
AI 只能帮你整理资料、找法条、找案例、起草文书，
但最终怎么判断、怎么决策，一定要你自己来。

---

### 2. 绝对不要输入客户保密信息和案件秘密！

律师的保密义务是职业道德，也是法律义务。

**绝对不要**：
- 把客户的合同、商业秘密输入公有 AI
- 把未公开的案件信息、策略输入公有 AI
- 把带当事人姓名、公司名的内容粘贴进去

如果要用，一定要：
- 完全脱敏，去掉所有能识别出主体的信息
- 用律所内部部署的私有化 AI 服务

---

### 3. AI 会编造法条和案例，而且特别像真的！

这是法律 AI 最危险的地方：
- 它会编造根本不存在的法条，还说得有模有样
- 它会编造根本不存在的案例和判决
- 它会引用已经废止的司法解释，还说这是现行有效
- 它会把 A 法条的内容安到 B 法条头上

**每一条 AI 引用的法条，你都必须去原文核对！**
**每一个 AI 说的案例，你都必须去裁判文书网搜一下是不是真的！**

不要偷懒，不然会出大事！

---

### 4. 法律是有时效性的，AI 的知识可能过时了

法律一直在变：
- 新的法律不断出台
- 旧的法律不断修订、废止
- 司法解释一直在更新
- 裁判观点一直在变化

AI 的训练数据是截止到某个时间点的，可能不知道最新的变化。

**重要的法条，一定要去查最新的版本！**
**重要的案例，一定要看最新的裁判倾向！**
