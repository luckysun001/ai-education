# 金融行业 AI 应用指南

适合：分析师、研究员、投资经理、风控、产品经理、财务、会计

金融行业是数据密集型行业，也是 AI 应用最成熟、价值最大的行业之一。

---

## 这个行业可以用 AI 做什么

### 场景 1：数据分析和报告撰写

**适用人群**：研究员、分析师、投研人员

**能解决的问题**：
- 数据太多，看不过来
- 写报告太慢，加班写
- 找数据、整理数据花太多时间
- 大量重复性的格式化报告

**具体用法**：

#### 1.1 财报分析和解读

```
你是一位资深的股票分析师，有 10 年的投研经验，
擅长从财报中发现问题和机会。

这是 [公司名称] [2024 年 Q1 / 年报] 的财报数据：

[粘贴核心财务数据，或者财报的文字部分]

请帮我做全面的财报分析：

一、核心数据概览
1. 营收、利润、现金流的核心数据
2. 同比/环比增长情况
3. 和市场预期的对比（如果知道预期的话）

二、亮点和超预期的地方
1. 哪些数据/业务表现特别好？
2. 为什么好？是偶然还是趋势？
3. 市场之前有没有 price in？

三、隐忧和低于预期的地方
1. 哪些地方表现不好？
2. 是短期因素还是长期问题？
3. 有没有什么风险信号？

四、分业务分析
1. 每个业务线的表现
2. 哪个业务在增长？哪个在下滑？
3. 业务结构有没有变化？

五、盈利能力分析
1. 毛利率、净利率、ROE 等指标的变化
2. 费用率的变化
3. 盈利能力是在改善还是恶化？

六、资产负债表和现金流
1. 有没有偿债风险？
2. 现金流健康吗？
3. 有没有什么异常的科目？

七、管理层指引和电话会议要点
（如果有电话会议纪要的话）
1. 管理层怎么看下个季度/明年？
2. 有什么重要的信息？
3. 语气是乐观还是谨慎？

八、投资观点
1. 这份财报整体是利好还是利空？
2. 对公司的投资逻辑有没有变化？
3. 应该加仓、减仓还是持有？
4. 接下来要重点跟踪什么？

要求：
- 客观中立，不要太乐观也不要太悲观
- 有数据支撑，不要空泛的结论
- 不仅要说「是什么」，还要说「为什么」和「意味着什么」
- 指出风险和不确定性，不要说得太绝对
```

---

#### 1.2 行业数据和研报总结

```
你是一位行业研究员，覆盖 [行业，如：新能源 / 消费 / 医药]。

以下是最近的 [5 篇行业研报 / 行业数据 / 政策文件]：

[粘贴研报摘要/数据]

请帮我总结和分析：

1. 所有研报的共识是什么？
   - 大家都认同的行业趋势？
   - 大家都看好的方向？

2. 分歧点是什么？
   - 不同券商/机构有什么不一样的观点？
   - 为什么会有分歧？

3. 超预期和低于预期的点
   - 哪些数据/变化超出了之前的预期？
   - 哪些地方比大家想的要差？

4. 关键数据和图表
   - 最重要的 5 个数据是哪些？
   - 这些数据说明了什么？
   - 接下来要跟踪哪些数据？

5. 政策影响分析（如果有政策的话）
   - 对行业整体是利好还是利空？
   - 对哪些公司利好最大？对哪些利空？
   - 影响是短期还是长期？

6. 投资建议
   - 这个行业接下来应该怎么看？
   - 看好哪些细分方向？
   - 有什么风险要注意？

最后，用 300 字以内的篇幅，给基金经理写一个投资要点的摘要。
```

#### 1.3 写日常点评和市场复盘

```
你是一位资深的市场策略分析师。

今天的市场情况是：
[简单描述今天的大盘、板块、重要新闻]

请帮我写一份今日市场复盘：

1. 市场概览
   - 大盘表现
   - 涨跌家数
   - 成交量变化

2. 板块分析
   - 涨幅靠前的板块，为什么涨？
   - 跌幅靠前的板块，为什么跌？
   - 有没有什么板块轮动的信号？

3. 重要新闻和事件影响
   - 今天有什么重要的新闻/政策/数据？
   - 市场是怎么反应的？
   - 影响是短期还是长期？

4. 资金动向
   - 北向资金/南向资金流向
   - 机构在买什么卖什么？
   - 情绪指标怎么样？（恐慌/贪婪指数等）

5. 后市展望和操作建议
   - 接下来市场会怎么走？
   - 有什么机会和风险？
   - 投资者应该怎么做？

要求：
- 客观，不要屁股决定脑袋
- 有数据支撑
- 不要模棱两可，要有明确的观点，但也要说清楚前提和风险
- 字数控制在 800-1000 字
- 语言要专业，但不要太晦涩
```

### 场景 2：投资研究和决策辅助

**适用人群**：基金经理、投资经理、研究员

```
你是一位资深的投资专家，经历过多轮牛熊，有成熟的投资体系。

我正在研究 [公司/行业]，目前的情况是：
[描述你对这个公司/行业的理解]

看多的理由有：
1. [理由 1]
2. [理由 2]
3. [理由 3]

看空的理由有：
1. [理由 1]
2. [理由 2]
3. [理由 3]

请帮我做全面的分析：

一、正反方辩论
1. 站在多头的角度，怎么反驳空头的观点？
2. 站在空头的角度，怎么反驳多头的观点？
3. 双方的论点分别在什么前提下成立？

二、关键假设和验证
1. 多头的核心假设是什么？怎么验证这些假设对不对？
2. 空头的核心假设是什么？怎么验证这些假设对不对？
3. 哪些数据出来可以证伪/证实一方的观点？

三、赔率和胜率分析
1. 如果看多对了，能赚多少？
2. 如果看错了，会亏多少？
3. 你觉得胜率大概有多少？
4. 这个价格值得下注吗？

四、情景分析
1. 乐观情景：发生概率？上涨空间？
2. 中性情景：发生概率？涨跌幅？
3. 悲观情景：发生概率？下跌空间？

五、催化剂和风险点
1. 接下来有什么催化剂能让股价变动？（财报、政策、数据...）
2. 有什么黑天鹅风险需要防范？
3. 什么情况下应该止损？

六、最终的投资建议
1. 综合来看，应该买、卖还是持有？
2. 仓位建议是多少？
3. 止盈和止损位设在哪里？
4. 接下来要重点跟踪什么？

最后，用 3 句话总结最核心的投资逻辑。
```

### 场景 3：风险控制和合规

**适用人群**：风控、合规、审计

#### 3.1 异常交易检测和分析

```
你是一位资深的风控专家。

我们发现有一个账户最近的交易有点异常，数据如下：
[粘贴交易数据/行为数据]

请帮我分析：

1. 哪些地方确实异常？
   - 和历史行为比，有什么不一样？
   - 和同类型的其他账户比，有什么不一样？
   - 哪些指标超出了正常范围？

2. 可能的原因分析
   - 原因 1：正常的交易策略变化？
   - 原因 2：用户账号被盗？
   - 原因 3：洗钱/内幕交易等违规行为？
   - 原因 4：其他？

3. 每个原因的验证方法
   - 怎么验证是不是原因 1？要看什么数据？
   - 怎么验证是不是原因 2？要看什么数据？

4. 风险等级评估
   - 这个异常的严重程度？（低/中/高/极高）
   - 可能的损失有多大？
   - 紧急程度？要不要马上冻结？

5. 处置建议
   - 第一步应该做什么？
   - 第二步应该做什么？
   - 怎么和客户沟通？
   - 后续怎么监控？
```

---

#### 3.2 合规审查和风险点排查

```
你是一位金融合规专家，熟悉 [银行业 / 证券业 / 基金业] 的监管要求。

请帮我审查以下 [合同 / 产品宣传材料 / 销售话术]：

[粘贴内容]

请从合规角度全面审查：

1. 有没有违反监管规定的地方？
   - 逐条列出来，指出哪句话/哪个条款有问题
   - 违反了哪条监管规定？
   - 可能会有什么处罚？

2. 有没有误导性表述？
   - 有没有夸大收益？
   - 有没有隐瞒风险？
   - 有没有承诺保本保收益？
   - 有没有不当类比？

3. 信息披露是不是充分？
   - 风险提示有没有说清楚？
   - 费用有没有说清楚？
   - 重要信息有没有放在显眼的位置？

4. 格式和程序有没有问题？
   - 有没有需要客户签字确认的地方？
   - 有没有什么必备的条款漏掉了？

5. 修改建议
   - 有问题的地方应该怎么改？
   - 给出具体的修改后的表述

6. 风险等级
   - 整体的合规风险怎么样？（低/中/高）
   - 哪些是必须马上改的？
   - 哪些可以慢慢优化？
```

### 场景 4：财务和会计

**适用人群**：财务、会计、审计

#### 4.1 财务数据整理和核对

```
你是一位资深的注册会计师。

以下是 [X 公司] 的财务数据，来自 [三个不同的来源，如：财报、审计、内部报表]：

[粘贴数据]

请帮我核对这些数据：

1. 哪些地方对不上？
   - 列表说明每一个差异点
   - 差异有多大？金额和比例

2. 差异的可能原因
   - 是口径不一样？
   - 是统计时间不一样？
   - 是计算错误？
   - 还是有操纵的可能？

3. 哪些差异是可以接受/解释的？
   - 为什么这些差异是正常的？

4. 哪些差异是需要警惕/进一步调查的？
   - 为什么这些差异不正常？
   - 应该怎么调查？找谁问？

5. 应该怎么调整，让这些数据对得上？
   - 给出调整后的统一口径的数据
```

---

#### 4.2 财务建模和预测

```
你是一位财务建模专家。

我们要给 [公司] 做未来 3 年的财务预测模型。

目前的已知条件和假设：
1. [假设 1，如：营收每年增长 20%]
2. [假设 2，如：毛利率维持 45%]
3. ...

请帮我搭建一个完整的财务预测模型：

1. 利润表预测
   - 营收（分业务线，如果可以的话）
   - 成本和各项费用
   - 税
   - 净利润

2. 资产负债表预测
   - 主要的资产和负债科目
   - 营运资本

3. 现金流量表预测
   - 经营、投资、筹资现金流
   - 期末现金

4. 关键财务指标
   - 盈利能力指标
   - 运营效率指标
   - 偿债能力指标

5. 敏感性分析
   - 如果营收增长只有 10%（而不是 20%），结果会怎样？
   - 如果毛利率下降 5 个点，结果会怎样？
   - 哪些假设对结果影响最大？

6. 情景分析
   - 乐观情景
   - 中性情景
   - 悲观情景

最后，说明这个模型的主要风险和局限性，以及使用时要注意什么。
```

### 场景 5：产品和运营

**适用人群**：金融产品经理、运营

#### 5.1 用户行为分析和画像

```
你是一位用户增长和数据分析专家。

以下是我们产品的用户行为数据：
[粘贴数据，如：不同年龄段的行为、不同客群的转化率等]

请帮我分析：

1. 用户画像总结
   - 我们的典型用户是什么样的？
   - 有几类用户？每类的特点是什么？

2. 行为规律和洞察
   - 用户在什么时间最活跃？
   - 什么行为和高留存/高转化相关？
   - 什么行为是流失的信号？

3. 转化漏斗分析
   - 每个步骤的转化率是多少？
   - 哪个步骤流失最多？
   - 为什么会在这里流失？
   - 怎么优化？

4. 不同客群的差异
   - 新用户 vs 老用户
   - 高净值用户 vs 普通用户
   - 不同渠道来的用户有什么不一样？

5. 增长建议
   - 拉新：应该去哪里找更多用户？
   - 转化：怎么提高转化率？
   - 留存：怎么让用户留下来？
   - 每个建议给出具体的可执行的方案，以及预估的效果。
```

#### 5.2 客服和智能问答

```
你是一位金融客服专家。

我们的用户经常问以下这些问题：
[列出常见的 10-20 个问题]

请帮我：

1. 给每个问题写一个标准的回答话术
   - 专业、准确
   - 易懂，不要太多术语
   - 友好，有温度
   - 不要有合规风险

2. 把这些问题分类
   - 可以分成几大类？
   - 哪类问题问得最多？

3. 针对问得最多的 3 类问题，给出：
   - 怎么在产品里优化，减少用户提问？
   - 怎么用 FAQ / 机器人自动回答，节省人工？

4. 有没有什么问题是用户可能会问，但我们现在没覆盖到的？
   - 列出 10 个潜在的问题
   - 每个问题也写好标准答案
```

## 真实案例

### 案例 1：研究员用 AI 读财报，效率提升 5 倍

**背景**：某卖方研究员，财报季的时候一天要读十几份财报，写点评，根本写不完。

**AI 用法**：
1. 把财报 PDF 转成文字，喂给 AI（用 Claude 等长上下文模型）
2. 让 AI 按模板写财报点评初稿
3. 自己核对关键数据，加入自己的观点和判断
4. 让 AI 调整语气和结构，做成符合公司要求的格式

**效果**：原来读一份财报+写点评要 2 小时，现在 20 分钟就能搞定，质量还更稳定。省下来的时间可以去做更深度的研究、和上市公司交流。

---

### 案例 2：用 AI 快速整理会议纪要和调研纪要

**背景**：某基金经理，一天开好几个电话会、调研会，录音几小时，听不过来。

**AI 用法**：
1. 用语音转文字工具，把录音转成文字
2. 喂给 AI，让它整理会议纪要：
   - 核心观点
   - 重要数据
   - 超预期的点
   - 风险和问题
   - 管理层说了什么值得注意的话
3. 让 AI 提取出后续要跟踪的问题和行动项

**效果**：原来 2 小时的会，要花 1 小时整理，现在 5 分钟就能拿到核心信息。一天的会，原来第二天才能消化完，现在当天就能全部整理完。

## 注意事项

### ❌ 不要完全相信 AI 的财务数据和计算

AI 经常会：
1. 算错数（加减乘除都会错）
2. 记错财务指标的公式
3. 混淆不同的会计口径
4. 编造不存在的数据

**重要的数字，一定要自己再算一遍！**

---

### ❌ 不要让 AI 替你做投资决策

AI 可以帮你：
- 整理信息
- 分析数据
- 指出你漏掉的角度
- 做情景分析

但最终的投资决策一定要你自己做。
AI 不知道你的仓位、你的风险承受能力、你的投资期限。
而且 AI 没有办法对结果负责。

---

### ❌ 绝对不要输入敏感和涉密信息

金融行业的信息安全要求非常高：
- 客户数据、交易数据绝对不能输入公有 AI
- 内幕信息、未公开的研报观点绝对不能输入
- 公司内部的敏感信息绝对不能输入

**轻则违规，重则违法，千万注意！**

建议：
- 用公司内部部署的私有化 AI 服务
- 数据脱敏后再用
- 重要的内容，还是自己写
