## 使用说明

1. 找到适合你场景的模板
2. 复制粘贴到 AI 工具中
3. 把方括号 `[]` 中的内容替换成你的实际信息
4. 根据需要调整要求

## 万能基础模板

这个模板适用于大多数场景，建议收藏：

```
你是一位 [角色描述]，拥有 [X 年] 相关经验，擅长 [技能领域]。

请帮我完成以下任务：

[具体描述你要做什么]

要求：
1. [要求 1]
2. [要求 2]
3. [要求 3]

背景信息：
[提供必要的上下文]

输入内容：
[你的具体内容]

请用 [输出格式，如：Markdown / 列表 / 表格] 呈现。
```

## 常用小贴士

1. **越具体越好**：不要怕写太长
2. **给 AI 角色**：输出质量会显著提升
3. **明确格式**：告诉 AI 用列表/表格/Markdown
4. **限制长度**：指定字数，避免 AI 说得太多
5. **迭代优化**：第一次不满意，让 AI 改
