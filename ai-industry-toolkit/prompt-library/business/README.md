## 商业分析

### 模板 1：商业计划书（BP）框架

```
你是一位资深的风险投资分析师，看过成千上万份商业计划书。

我要做的项目是：[一句话描述你的项目]
项目所处的阶段：[想法阶段 / 原型阶段 / 已有收入 / 快速增长]
目标：[融资 / 梳理思路 / 给合伙人看]

请帮我搭一个完整的商业计划书框架：

1. 执行摘要（Executive Summary）
   - 一句话介绍
   - 解决了什么痛点
   - 我们的解决方案
   - 目标市场有多大
   - 为什么是我们做
   - 财务亮点

2. 问题与痛点
   - 用户有什么问题？
   - 现在他们是怎么解决的？
   - 有什么不满意的地方？
   - 痛点有多痛？

3. 解决方案
   - 我们的产品/服务是什么？
   - 怎么解决这个问题？
   - 核心功能有哪些？
   - 使用流程是怎样的？

4. 市场分析
   - 市场规模有多大（TAM/SAM/SOM）？
   - 市场增长速度？
   - 未来趋势是怎样的？

5. 竞争格局
   - 有哪些直接/间接竞争对手？
   - 他们的优势/劣势是什么？
   - 我们和他们有什么不同？
   - 我们的护城河是什么？

6. 商业模式
   - 怎么赚钱？（收入来源）
   - 定价策略？
   - 单位经济模型（LTV/CAC）？
   - 成本结构？

7. 运营和增长
   - 怎么获取第一批用户？
   - 增长策略是什么？
   - 关键指标有哪些？
   - 里程碑规划？

8. 团队介绍
   - 核心团队成员背景
   - 为什么这个团队能做成这件事？
   - 顾问/投资人（如果有）

9. 财务预测
   - 未来 3 年的收入/成本/利润预测
   - 关键假设是什么？
   - 盈亏平衡点在哪里？

10. 融资需求
    - 需要融多少钱？
    - 稀释多少股份？
    - 钱花在什么地方？
    - 这笔钱能撑到什么时候？

11. 风险与应对
    - 主要的风险有哪些？
    - 怎么应对这些风险？

12. 附录
    - 补充材料（用户调研数据、原型截图等）

对于每个部分，请说明：
1. 这个部分重点要写什么？
2. 投资人最关心什么？
3. 常见的坑有哪些？
4. 给一个简单的示例
```

### 模板 2：竞品分析报告

```
你是一位商业情报分析专家。

我们的产品是：[你的产品]
我们的核心竞品是：[竞品 A]、[竞品 B]、[竞品 C]

请帮我做一份详细的竞品分析报告，包含以下维度：

一、基本信息对比
用表格形式列出：
- 公司背景、成立时间
- 融资/估值情况
- 团队规模
- 用户规模/营收规模

二、产品功能对比
用表格形式，对比核心功能：
- 功能 1：竞品 A 情况 / 竞品 B 情况 / 我们的情况
- 功能 2：...
- 每个功能打个分（1-5 分）

三、用户体验对比
- 界面设计对比
- 使用流畅度
- 新手友好度
- 移动端体验

四、价格策略对比
- 各自的定价方式
- 性价比分析
- 促销活动情况

五、运营策略对比
- 他们是怎么获客的？
- 做了哪些营销活动？
- 用户运营做得怎么样？
- 内容/社区做得怎么样？

六、优势与劣势分析
对每个竞品：
- 核心优势是什么（抄不来的那种）？
- 明显的劣势是什么？
- 如果我们要打，应该从哪里切入？

七、近期动态
- 他们最近半年有什么大动作？
- 迭代了什么功能？
- 战略方向有什么变化？

八、总结与建议
1. 竞品做得好的、我们应该学习的地方
2. 竞品做得不好的、我们可以利用的机会点
3. 我们的差异化竞争策略建议
4. 3 个月内的行动建议
```

## 谈判准备

### 模板 3：谈判前准备清单

```
你是一位谈判专家，拥有丰富的商业谈判经验。

我即将要进行一场关于 [谈判主题] 的谈判，
对方是：[对方是谁，什么角色]
我们的关系是：[客户 / 供应商 / 合作伙伴 / 员工]

请帮我做全面的谈判前准备：

一、谈判目标设定
1. 最优目标（Best Case）：我们最理想的结果是什么？
2. 预期目标（Target）：我们正常能达成什么？
3. 底线目标（Walk Away）：低于这个就不谈了，底线是什么？
4. 替代方案（BATNA）：如果谈不成，我们有什么备选方案？

二、我方筹码分析
1. 我们的优势有哪些？（按重要性排序）
2. 我们的劣势有哪些？
3. 哪些优势是对方在乎的？
4. 哪些可以用来让步/交换？

三、对方筹码分析
1. 对方的优势有哪些？
2. 对方可能想要什么？
3. 对方的底线可能在哪里？
4. 对方的压力是什么（有什么时间/业绩压力？）

四、议题和优先级
这次谈判涉及哪些议题？按重要性排序：
1. 议题 A：我方期望 / 对方可能期望
2. 议题 B：我方期望 / 对方可能期望
...

五、让步策略
我们有什么可以让步的？
- 哪些是绝对不能让的？
- 哪些可以让，但要换东西回来？
- 让步的顺序是怎样的？
- 每次让步，我们想要换回什么？

六、开场和议程
1. 怎么开场比较好？（先拉家常？还是直接切入？）
2. 建议的讨论议程是怎样的？
3. 谁先开口？

七、可能的冲突和应对
1. 对方如果很强硬怎么办？
2. 对方如果打感情牌怎么办？
3. 对方如果拖延怎么办？
4. 谈判陷入僵局怎么办？

八、成交信号
怎么判断对方差不多可以接受了？

最后，给出 3 条最重要的谈判策略建议。
```

### 模板 4：高难度沟通准备

```
你是一位沟通专家，擅长处理困难的沟通场景。

我需要和 [对方是谁] 进行一次比较困难的沟通，
主题是：[要谈什么]
这个沟通的难点在于：[说明难点，比如：对方很情绪化 / 之前谈崩过 / 对方很强势]

我期望的沟通结果是：[想要达成什么]

请帮我准备：

一、沟通前的心态建设
1. 我应该抱着什么心态去谈？
2. 哪些情绪是我需要提前处理好的？
3. 如果对方情绪激动，我怎么应对？

二、开场怎么说？
请写 2-3 个不同风格的开场话术：
- 直接坦诚型
- 温和破冰型
- 问题导向型

三、核心信息表达
我要传达的核心信息是什么？
请帮我组织成「非暴力沟通」的表达方式：
- 观察（事实，不带评判）：
- 感受（我的感受是什么）：
- 需要（背后的需要是什么）：
- 请求（具体希望对方怎么做）：

四、对方可能的反应和应对
对方可能会有这些反应，我该怎么应对？
1. 如果对方拒绝/反对：
2. 如果对方情绪化/生气：
3. 如果对方回避/不说话：
4. 如果对方转移话题：

五、怎么把谈话拉回正轨？
如果谈话跑题了或者变味了，怎么优雅地拉回来？
请写 3 句可以用的话术。

六、怎么收尾？
不管谈得成不成，最后怎么收尾比较好？
- 如果谈成了：
- 如果没谈成：

七、注意事项
- 哪些话绝对不能说？
- 哪些雷区要避免？
- 什么信号说明应该暂停谈话？

最后，给我做一个「谈话前检查清单」。
```

## 团队管理

### 模板 5：绩效反馈（1 对 1）

```
你是一位擅长带团队的管理者。

我要给团队成员做绩效反馈，
他的名字是：[名字]
他的职位是：[职位]

这段时间他的表现：
- 做得好的地方：
  1. [具体例子 1]
  2. [具体例子 2]
- 需要改进的地方：
  1. [具体例子 1]
  2. [具体例子 2]
- 他的优点/长处：
- 他的不足/盲区：
- 他的职业发展诉求是：

请帮我设计整个 1 对 1 谈话的流程和内容：

一、开场（5 分钟）
- 怎么开场让他放松？
- 开场话术

二、肯定成绩（10 分钟）
- 具体表扬哪些点？
- 怎么表扬才真诚，不空洞？
- 引导他自己说说哪些地方做得好

三、改进建议（15 分钟）
- 怎么说不足他更容易接受？
- 对每个不足，给出具体的、可落地的改进建议
- 怎么和他达成共识，而不是我单方面说教？
- 话术示例

四、职业发展（10 分钟）
- 怎么聊他的职业规划？
- 怎么把公司需要和他个人发展结合起来？
- 接下来 3-6 个月的成长目标

五、行动和支持（5 分钟）
- 接下来具体的行动计划
- 我可以给他提供什么支持？
- 需要什么资源？

六、收尾
- 怎么收尾让他带着动力离开？
- 确认他没有疑问
- 鼓励的话

请特别注意：
- 所有反馈都要有具体的例子，不要空泛
- 对事不对人
- 多用提问，少用说教
- 正向反馈和负向反馈的比例大概是 3:1
```

## 求职面试

### 模板 6：面试准备

```
你是一位资深的面试辅导专家。

我要面试 [公司名称] 的 [职位名称] 岗位，
这个岗位的 JD（职位描述）是：

[粘贴 JD]

我的背景情况是：
[简单介绍自己的背景、经验、优势、劣势]

请帮我做面试准备：

一、公司和职位分析
1. 这个公司是做什么的？有什么特点？
2. 这个岗位核心是要做什么？
3. 他们最看重什么能力/经验？
4. 这个岗位可能面临的挑战是什么？

二、我的定位
1. 我的优势是什么？怎么在面试中体现？
2. 我的劣势是什么？怎么应对可能的质疑？
3. 我和其他候选人比，差异化在哪里？
4. 我的「个人品牌」是什么（3 个关键词）？

三、必问问题准备
准备以下问题的回答，每个回答按「STAR 法则」组织（情境-任务-行动-结果）：

1. 自我介绍（3 分钟版本 / 1 分钟版本）
2. 为什么想换工作？
3. 为什么想来我们公司？
4. 介绍一个你最有成就感的项目
5. 说一个你遇到的最大的困难，你是怎么解决的？
6. 说一个你失败/犯错的经历，你学到了什么？
7. 你的优点是什么？缺点是什么？
8. 未来 3-5 年的职业规划是怎样的？
9. 你有什么问题要问我们？

对每个问题，请给出：
- 回答要点
- STAR 框架填充
- 可以突出什么能力/特质
- 有什么坑要避免

四、反问问题清单
准备 5-8 个可以问面试官的好问题，
按不同面试官准备（HR / 业务负责人 / 高管）：
- 问 HR 的问题
- 问直属领导的问题
- 问高管的问题

五、可能的压力面试问题
如果被问到以下挑战性问题，怎么回答？
1. 我觉得你的经验不太够，你怎么看？
2. 这个岗位竞争很激烈，你比其他人强在哪里？
3. 你期望的薪资是多少？

六、面试前最后 Checklist
- 再确认一遍面试时间、地址/链接
- 着装建议
- 心态调整建议
- 面试结束后跟进的邮件模板
```

## 沟通表达

### 模板 7：电梯演讲（Elevator Pitch）

```
你是一位演讲教练。

我需要一个 [30 秒 / 1 分钟 / 3 分钟] 的电梯演讲，
场景是：[比如：融资 pitch / 社交场合自我介绍 / 面试开场]

我要介绍的是：[自己 / 我的项目 / 我的产品]

核心信息：
1. 我是谁 / 我们是做什么的
2. 解决了什么问题
3. 有什么不一样的地方
4. 取得了什么成绩
5. （可选）我需要什么

请帮我写 2 个不同风格的版本：

版本 1：简洁有力型
- 每一句话都有信息量
- 没有废话

版本 2：故事/情感型
- 从一个问题/痛点切入
- 更能打动人

每个版本写完后，请说明：
- 这个版本适合什么场景？
- 讲的时候要注意什么语气/节奏？
- 有什么肢体语言建议？
```

## 商务类 Prompt 技巧

1. **给具体背景**：商务场景非常依赖上下文，越详细越好
2. **明确角色**：你是谁，对方是谁，你们是什么关系？
3. **设定目标**：你想要达到什么具体结果？
4. **要方案，不只要答案**：让 AI 给多个选项，分析优缺点
5. **要话术**：商务沟通中，怎么说比说什么更重要，直接要可套用的话术
