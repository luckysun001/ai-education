## 头脑风暴

### 模板 1：通用头脑风暴

适用场景：想点子、找思路

```
你是一位创意总监，拥有 15 年的广告/创意行业经验，
擅长从不同角度思考问题，总能想出让人眼前一亮的点子。

我们需要 brainstorm 关于 [主题] 的创意。

背景信息：
- 目标受众：[谁]
- 目标/目的：[想要达到什么效果]
- 限制/约束：[比如：预算有限 / 不能提到竞品 / 不能超过 30 秒]

请从以下几个角度，每个角度给出 5-8 个创意点子：

1. 最常规/最安全的思路
2. 最大胆/最有争议的思路
3. 最有趣/最好玩的思路
4. 最感人/最能引起情感共鸣的思路
5. 最意想不到/反直觉的思路
6. 可以蹭热点/借势的思路

对于每个点子，请：
- 用一句话说明核心创意
- 简单说一下怎么执行
- 给一个「惊艳程度」评分（1-10 分）
- 给一个「执行难度」评分（1-10 分）

最后，挑出 3 个你觉得最好的点子，说明为什么推荐。

要求：
- 点子要具体，不要太笼统
- 要敢想，哪怕听起来很「离谱」
- 数量优先，先追求数量再筛选质量
```

### 模板 2：反向思考头脑风暴

```
我们的目标是 [目标]。

常规的思路是 [描述大家通常会怎么做]。

但这次我们反过来想：
「如果我们想要 [完全相反的目标，比如：失败/让用户讨厌/没人记得住]，
我们应该怎么做？」

请列出 10 个「反常识」的做法：

1. [做法 1]
2. [做法 2]
...

然后，从这些「反做法」中反向思考：
- 哪些点反过来用，可能会产生意想不到的效果？
- 哪些常规思路其实是错误的？我们一直在做但其实没用？
- 有没有可以「反其道而行之」的机会？

最后，给出 3 个从反向思考得到的启发，以及可以落地的创意点。
```

请帮我构思 5 个完全不同方向的创意方案：

方案 1：情感共鸣路线
- 核心概念：
- 执行要点：
- 为什么有效：
- 可能的风险：

方案 2：有趣好玩路线
- 核心概念：
- 执行要点：
- 为什么有效：
- 可能的风险：

方案 3：干货实用路线
- 核心概念：
- 执行要点：
- 为什么有效：
- 可能的风险：

方案 4：社会议题路线

- 执行要点：
- 为什么有效：

### 模板 4：创意发散 - SCAMPER 方法

```
用 SCAMPER 方法帮我对 [现有产品/创意] 进行发散思考。

SCAMPER 是：
S - Substitute（替代）：什么东西可以被替代？
C - Combine（合并）：可以把什么和什么合并？
A - Adapt（调整）：可以怎么调整适应新场景？
M - Modify（修改）：可以修改什么（大小、形状、颜色...）？
P - Put to other uses（其他用途）：还有别的用途吗？
E - Eliminate（消除）：可以去掉什么？
R - Reverse/Rearrange（反向/重新排列）：顺序反过来会怎样？

请对每个字母给出 2-3 个具体的想法：

S - 替代：
1. 
2. 

C - 合并：
1. 
2. 

...以此类推

最后，从所有想法中挑出 3 个最有潜力的，说明可以怎么落地。
```

## 内容策划

### 模板 5：文章/视频选题策划

```
你是一位资深的内容策划专家。

我们要做一个 [公众号 / B站 / 小红书 / 抖音] 账号，
定位是 [账号定位]，目标受众是 [谁]。

我们想做一期关于 [大主题] 的内容，请帮我策划：

1. 5 个不同角度的选题
   - 每个选题写一个吸引人的标题
   - 说明这个选题的切入点
   - 预估受欢迎程度（1-10 分）
   - 预估制作难度（1-10 分）

2. 对每个选题，列出内容大纲
   - 开头怎么吸引人？
   - 主体分几个部分？
   - 每个部分的核心要点？
   - 结尾怎么收尾/引导互动？

3. 推荐 3 个可以引用的案例/故事/数据

4. 同类型内容的爆款分析
   - 这类内容的爆款有什么共同点？
   - 我们可以怎么差异化？

5. 给内容加「传播点」
   - 什么点会让用户愿意转发？
   - 什么点会引起讨论/争议？
```

### 模板 6：系列内容规划

```
我们要做一个关于 [大主题] 的系列内容（比如 10 期课程/专栏），
目标受众是 [谁]，目标是 [学完后能达到什么效果]。

请帮我规划整个系列的内容结构：

1. 整个系列的定位和目标
   - 用户为什么要学这个系列？
   - 学完后能获得什么？

2. 内容框架（分 8-12 期）
   第 1 期：[主题] - 目标：[学完能做什么]
   第 2 期：[主题] - 目标：[学完能做什么]
   ...

3. 内容难度曲线
   - 哪几期是基础？
   - 哪几期是进阶？
   - 哪几期最难？

4. 每期内容的形式建议
   - 理论讲解？
   - 案例分析？
   - 实战演示？
   - 嘉宾访谈？

5. 互动和作业设计
   - 每期布置什么作业？
   - 怎么检验学习效果？

6. 引流和转化设计
   - 怎么让用户从第 1 期追到最后一期？
   - 哪些地方可以设计转化点？
```

## 命名/起名

### 模板 7：产品/项目/公司起名

```
你是一位品牌命名专家，擅长起好听、好记、有内涵的名字。

我们需要给 [产品/项目/公司] 起名字，具体信息：

产品/项目是做什么的：[一句话描述]
目标用户是谁：[谁]
品牌调性：[比如：科技感 / 亲切可爱 / 高端奢华 / 文艺清新]
关键词：[可以包含这些相关的词，比如：云、智、生活...]

命名要求：
1. 字数：[2 字 / 3-4 字 / 都可以]
2. 要 [容易发音 / 容易拼写 / 容易记住]
3. 要有 [现代感 / 传统感 / 国际感]
4. 最好能 [有寓意 / 有故事 / 引发联想]
5. 避免：[生僻字 / 多音字 / 谐音有不好的意思 / 和知名品牌撞名]

请从以下几个方向，每个方向给出 5 个备选名字：

方向 1：直白描述型
- 一看就知道是做什么的
- 例子：支付宝、微信读书

方向 2：抽象意境型
- 有想象空间，不那么直白
- 例子：字节跳动、蚂蚁

方向 3：有趣好玩型
- 亲切，容易传播
- 例子：小红书、飞书

方向 4：外来/音译型
- 听起来比较国际化
- 例子：谷歌、特斯拉

方向 5：组合创新型
- 把两个不相关的词组合在一起
- 例子：小米、苹果

对于每个名字，请：
1. 写出名字
2. 简单解释含义/寓意
3. 给一个「好感度」评分（1-10 分）

最后，给出你的 Top 3 推荐，并说明推荐理由。

Bonus：如果能顺便想一句 Slogan 就更好了！
```

## 故事创作

### 模板 8：短视频脚本/小故事

```
你是一位编剧，擅长写有反转、能打动人的短故事。

请帮我写一个 [1 分钟 / 3 分钟] 的短视频脚本，主题是 [主题]。

风格要求：[温馨治愈 / 搞笑反转 / 引人深思 / 感人泪目]

故事背景：
[可以给出一些背景，或者让 AI 自由发挥]

请按以下格式写：

## 核心概念
一句话说明这个故事讲了什么。

## 人物设定
- 主角：
- 配角：

## 完整脚本
按场景分镜头，每个镜头写清楚：画面 + 台词/旁白 + 时长

## 故事看点
- 哪里最打动人？
- 反转在哪里？
- 用户看完会有什么感受？

## 结尾金句
最后可以升华主题的一句话（适合做字幕）。
```

## 创意类 Prompt 技巧

1. **数量优先**：头脑风暴时先追求数量，再筛选质量
2. **设定角色**：创意总监、广告人、编剧... 不同角色不同视角
3. **给限制**：「如果预算只有 100 块怎么办？」「如果必须 24 小时内做完怎么办？」限制往往催生好创意
4. **结合热点**：告诉 AI 当前有什么热点，让它帮你想怎么借势
5. **不要怕「离谱」**：很多好创意一开始听起来都很离谱

### 进阶技巧：用「如果...会怎样？」激发创意

```
如果我们的用户是 [老人/小孩/外国人/外星人 / 狗] 会怎样？
如果这个产品 [免费 / 卖 100 万 / 只能用一次 / 会过期] 会怎样？
如果 [政府 / 明星 / 你妈 / 你的老板] 看到这个会怎样？
```
