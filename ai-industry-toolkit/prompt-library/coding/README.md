## 代码生成

### 模板 1：从零写函数/类

适用场景：需要写一个新的函数或类

```
你是一位有 10 年经验的资深 [编程语言] 开发工程师，
擅长编写清晰、可维护、性能优秀的代码。

请帮我写一个 [函数/类]，功能是：

[详细描述这个函数/类需要做什么]

要求：
1. 代码风格：[简洁高效 / 易于理解 / 企业级]
2. 要有详细的注释，说明每个参数和返回值
3. 要处理边界情况和异常
4. 遵循 [PEP 8 / Google 风格 / Airbnb 风格] 规范
5. 性能考虑：[如果有性能要求请说明]

请给出：
1. 完整的代码
2. 设计思路说明
3. 3 个使用示例（包含正常情况和边界情况）
4. 可能的优化方向
```

### 模板 2：写单元测试

```
你是一位注重质量的测试开发工程师。

请为以下代码编写单元测试：

[粘贴代码]

要求：
1. 使用测试框架：[pytest / unittest / Jest / JUnit 等]
2. 覆盖率：至少覆盖 80% 的分支
3. 包含：
   - 正常用例
   - 边界用例
   - 异常/错误用例
4. 每个测试用例要有清晰的名称和注释
5. 使用 Arrange-Act-Assert 模式组织代码

请给出完整的测试代码，并说明测试策略。
```

## 代码解释

### 模板 3：解释复杂代码

适用场景：看不懂别人写的代码，或者看开源项目

```
你是一位耐心的编程导师，擅长用简单易懂的语言解释复杂的代码。

请帮我解释以下这段代码：

[粘贴需要解释的代码]

请从以下几个方面进行解释：

1. 整体功能
   - 这段代码是做什么的？
   - 用在什么场景下？

2. 核心逻辑
   - 主要的执行流程是什么？
   - 用流程图或步骤说明

3. 关键技术点
   - 用到了什么算法/设计模式？
   - 有什么巧妙的写法？

4. 数据结构
   - 输入是什么格式？
   - 输出是什么格式？

5. 可能的问题
   - 这段代码有什么潜在的 bug？
   - 性能可能有什么问题？
   - 可以怎么改进？

如果有特别难懂的部分，请单独拎出来详细解释。

要求：
- 语言通俗易懂，不要太专业的术语
- 用例子说明会更好
- 假设我是一个初学者
```

### 模板 4：理解整个项目/仓库

```
你是一位软件架构师，擅长快速理解新项目的代码结构。

这是项目的目录结构：

[粘贴目录结构，比如 tree 命令的输出]

核心文件的内容（可以选几个关键文件）：
[关键文件 1 的内容]
[关键文件 2 的内容]

请帮我分析这个项目：

1. 项目是做什么的？
   - 核心功能是什么？
   - 目标用户是谁？

2. 整体架构
   - 用了什么技术栈？
   - 代码的分层结构是怎样的？
   - 关键模块有哪些？各自的职责？

3. 执行流程
   - 数据是怎么流动的？
   - 从入口到输出的完整流程？

4. 核心技术点
   - 用到了什么关键算法/设计模式？
   - 有什么值得学习的地方？

5. 给新人的建议
   - 如果我要给这个项目贡献代码，应该从哪里入手？
   - 阅读代码的顺序建议？
```

## 代码调试

### 模板 5：帮我找 bug

```
你是一位经验丰富的调试专家，擅长快速定位问题。

我遇到了一个 bug，请帮我分析和定位。

问题描述：
[详细描述遇到的问题]

错误信息：
[粘贴报错信息/堆栈]

相关代码：
[粘贴可能有问题的代码]

我已经试过的方法：
1. [试过的方法 1]
2. [试过的方法 2]

请帮我：

1. 可能的原因分析
   - 列出 3-5 个最可能导致这个问题的原因
   - 按可能性从高到低排序

2. 排查步骤
   - 第一步应该做什么？
   - 第二步应该做什么？
   - 如何一步步缩小范围？

3. 验证方法
   - 怎么确认是不是某个原因？
   - 需要加什么日志/断点？

4. 修复建议
   - 如果定位到了问题，应该怎么修？
   - 有几种修复方案？各自的优缺点？

5. 预防措施
   - 以后怎么避免类似的问题？
```

### 模板 6：性能问题分析

```
你是一位性能优化专家。

我的代码运行太慢了，请帮我分析和优化。

代码功能：
[这段代码是做什么的]

当前性能表现：
- 输入数据量：[多大的数据]
- 运行时间：[现在需要多久]
- 期望运行时间：[希望优化到多久]

相关代码：
[粘贴代码]

请帮我：

1. 性能瓶颈分析
   - 这段代码最可能慢在哪里？
   - 时间复杂度是多少？
   - 空间复杂度是多少？

2. 性能分析步骤
   - 应该用什么工具/profile？
   - 重点看哪些指标？

3. 优化建议
   - 第一级优化（改动小，见效大）
   - 第二级优化（中等改动）
   - 第三级优化（大改，但效果最好）

4. 优化后的代码
   - 给出优化后的版本
   - 说明为什么这样改会变快
   - 估计优化后的性能提升

5. 注意事项
   - 优化可能带来的副作用？
   - 怎么验证优化是正确的？
```

## 代码重构

### 模板 7：代码质量提升

```
你是一位代码质量专家，擅长把「烂代码」改造成「优雅的代码」。

请帮我重构以下代码：

[粘贴需要重构的代码]

这段代码目前存在的问题：
1. [问题 1，比如：重复代码太多]
2. [问题 2，比如：命名不清晰]
3. [问题 3，比如：没有注释]
（如果不知道有什么问题，可以让 AI 先分析）

重构目标：
- 提高可读性
- 减少重复
- 提高可维护性
- 不改变原有功能

请帮我：

1. 先分析现有代码的问题
   - 列出主要的问题点
   - 每个问题给一个「严重程度」评分（1-10）

2. 重构后的代码
   - 给出完整的重构后的代码
   - 遵循最佳实践
   - 保持原有功能不变

3. 重构说明
   - 主要做了哪些改动？
   - 为什么这么改？
   - 带来了什么好处？

4. 验证建议
   - 怎么确保重构没有破坏功能？
   - 需要补充哪些测试？
```

## 代码审查

### 模板 9：帮我做 Code Review

```
你是一位严格但友好的高级工程师，正在帮我做 Code Review。

请审查以下代码：

[粘贴需要审查的代码]

这个代码的功能是：
[描述这段代码是做什么的]

请从以下维度进行审查：

1. 功能正确性
   - 有没有明显的 bug？
   - 边界情况处理了吗？
   - 异常处理完善吗？

2. 代码质量
   - 命名清晰吗？
   - 有没有重复代码？
   - 职责单一吗？
   - 注释充分吗？

3. 性能
   - 有性能问题吗？
   - 时间/空间复杂度可以优化吗？

4. 安全性
   - 有安全漏洞吗？
   - 输入验证了吗？
   - SQL 注入、XSS 等问题？

5. 最佳实践
   - 有没有违反最佳实践的地方？
   - 可以用什么设计模式改进？

请给出：
- 每个问题的具体位置（哪一行）
- 问题说明
- 修改建议
- 严重程度（Blocker / Critical / Major / Minor / Nitpick）

最后，给这个代码一个总体评分（1-10 分），并说明主要的改进方向。

请保持鼓励的语气，不要太打击人 😊
```

## 编程类 Prompt 技巧

1. **指定编程语言和版本**：比如「Python 3.10+」「TypeScript 5.0+」
2. **说明代码用途**：是脚本？还是库？还是生产环境代码？
3. **给代码上下文**：不要只贴一小段，AI 了解完整上下文会给出更好的建议
4. **指定代码风格**：PEP 8、Google Style、Airbnb Style 等
5. **要求解释**：不要只要代码，还要解释，学习效果更好

### 进阶技巧：让 AI 扮演不同角色

```
# 严厉的面试官
你是一位严厉的技术面试官，这段代码是候选人写的，请挑出所有问题...

# 友好的导师
你是一位耐心的编程导师，我是初学者，请帮我慢慢理解这段代码...

# 追求极致的性能专家
你是一位性能优化偏执狂，请把这段代码优化到极致...

# 安全审计专家
你是一位安全审计专家，请找出这段代码所有的安全漏洞...
```

不同的角色会给出完全不同视角的反馈！
