## 数据分析

### 模板 1：基础数据分析

适用场景：拿到一堆数据，不知道怎么分析

```
你是一位资深的数据分析师，拥有 10 年的数据分析经验。

以下是我需要分析的数据：

[粘贴数据，可以是表格、CSV、JSON 等格式]

请帮我做全面的数据分析，包含以下内容：

1. 整体概览
   - 数据的时间范围、数据量
   - 关键指标的平均值、最大值、最小值

2. 趋势分析
   - 整体趋势是上升还是下降？
   - 有没有明显的周期性？
   - 有没有异常点/突变点？

3. 结构分析
   - 各分类的占比情况
   - 哪个分类表现最好/最差？

4. 相关性分析（如果数据有多维度）
   - 哪些因素之间有相关性？

5. 关键发现
   - 列出 3-5 个最重要的发现

6. 行动建议
   - 基于分析结果，给出 3 条具体的建议

要求：
- 用通俗易懂的语言，不要太专业的术语
- 重点突出，结论明确
- 建议要具体可执行
```

### 模板 2：销售数据分析

```
你是一位销售数据分析专家。

以下是我们 [本月/本季度/本年] 的销售数据：

[粘贴销售数据]

请帮我分析：

1. 销售业绩总览
   - 总销售额、目标完成率
   - 同比/环比增长情况

2. 表现最好的
   - TOP 5 产品/区域/销售人员
   - 为什么表现好？

3. 表现最差的
   - 倒数 5 个产品/区域/销售人员
   - 可能的原因？

4. 趋势预测
   - 下个月/下个季度的销售预测
   - 可能的风险点

5. 改进建议
   - 如何提升销售额？给出 3 条具体建议
   - 应该重点关注哪些产品/区域？

请用 Markdown 格式，重点用粗体标出。
```

## 市场调研

### 模板 3：行业分析

```
你是一位行业研究专家，拥有 [XX] 年的相关行业研究经验。

请帮我做一份关于 [行业名称] 的行业分析报告。

分析维度：

1. 行业概况
   - 行业规模（市场大小）
   - 增长速度
   - 发展阶段（起步/快速增长/成熟/衰退）

2. 发展趋势
   - 未来 3-5 年的主要趋势
   - 可能的技术变革
   - 政策影响

3. 竞争格局
   - 主要玩家有哪些？
   - 市场份额大概是多少？
   - 各自的优势/劣势？

4. 机会与挑战
   - 这个行业的机会在哪里？
   - 主要的风险和挑战是什么？

5. 进入建议
   - 如果想进入这个行业，从哪里切入？
   - 需要具备什么能力/资源？

要求：
- 内容详实，有数据支撑（如果知道具体数据的话）
- 客观中立，不夸大也不贬低
- 给出明确的结论和建议
- 总字数约 1500 字
```

### 模板 4：目标用户画像

```
你是一位用户研究专家。

我们的产品是：[产品描述]
我们的目标用户是：[大概描述目标用户]

请帮我构建一个详细的用户画像，包含：

1. 基本属性
   - 年龄、性别、地域、职业、收入水平
   - 教育背景、家庭情况

2. 心理特征
   - 价值观、生活态度
   - 兴趣爱好、关注的话题
   - 痛点/焦虑点

3. 行为特征
   - 常用的 App/网站
   - 消费习惯（价格敏感？品牌敏感？）
   - 做决策的方式（冲动型？理性型？）

4. 使用场景
   - 什么时候/什么情况下会用我们的产品？
   - 想解决什么问题？
   - 期望得到什么结果？

5. 用户分类
   - 可以分成几类用户？
   - 每类的特点是什么？
   - 哪类是核心用户？

最后，给出针对这类用户的 3 条产品/营销建议。
```

## 竞品分析

### 模板 5：竞品对比分析

```
你是一位竞品分析专家。

我们的产品是：[你的产品描述]

请帮我分析以下几个竞品：

竞品 A：[竞品 A 名称]
竞品 B：[竞品 B 名称]
竞品 C：[竞品 C 名称] （可以继续添加）

请从以下维度进行对比分析：

1. 基本信息
   - 公司背景、成立时间
   - 融资/规模情况

2. 产品功能对比
   - 用表格形式列出核心功能的对比
   - 评分：好/中/差

3. 用户体验
   - 界面设计
   - 使用流畅度
   - 用户口碑

4. 价格策略
   - 定价方式
   - 性价比如何？

5. 优势与劣势
   - 每个竞品的核心优势
   - 每个竞品的明显劣势

6. 对我们的启示
   - 可以学习的地方
   - 可以差异化的机会点
   - 需要避免的坑

最后，用一个对比总结表格呈现所有维度的对比结果。
```

## 决策辅助

### 模板 6：决策分析 - 利弊分析

```
你是一位决策顾问，擅长用结构化的方式帮助做决策。

我面临的决策是：[清晰描述你要做的决策]

可选方案：
1. 方案 A：[描述方案 A]
2. 方案 B：[描述方案 B]
3. （可以继续添加方案）

我的情况/约束条件：
- [约束 1]
- [约束 2]
- [约束 3]

请帮我做全面的决策分析：

1. 每个方案的利弊分析
   - 方案 A 的优点（3-5 条）
   - 方案 A 的缺点（3-5 条）
   - 方案 B 的优点（3-5 条）
   - 方案 B 的缺点（3-5 条）

2. 风险评估
   - 每个方案可能的风险
   - 风险发生的概率（高/中/低）
   - 风险的影响程度（大/中/小）

3. 打分评估
   - 从以下几个维度给每个方案打分（1-10 分）：
     - 收益大小
     - 风险高低
     - 实施难度
     - 长期价值
   - 计算加权总分

4. 推荐建议
   - 综合分析，推荐哪个方案？
   - 为什么？给出 3 个核心理由
   - 实施的注意事项

要求：
- 客观中立，不要带偏见
- 考虑短期和长期影响
- 给出明确的结论，不要模棱两可
```

### 模板 7：SWOT 分析

```
你是一位战略顾问。

请帮我做一个 SWOT 分析，分析对象是：[公司/产品/项目名称]

S - Strengths（优势）：内部的优势
W - Weaknesses（劣势）：内部的劣势
O - Opportunities（机会）：外部的机会
T - Threats（威胁）：外部的威胁

请每个部分列出 5-8 条，然后基于 SWOT 分析，给出 4 个方向的战略建议：

1. SO 战略（优势 + 机会）：利用优势抓机会
2. WO 战略（劣势 + 机会）：克服劣势抓机会
3. ST 战略（优势 + 威胁）：利用优势应对威胁
4. WT 战略（劣势 + 威胁）：减少劣势，回避威胁

最后给出一个总结性的行动建议。
```

## 问题诊断

### 模板 8：问题根因分析

```
你是一位问题诊断专家，擅长用结构化思维分析问题的根本原因。

我遇到的问题是：[清晰描述遇到的问题]

问题的表现：
1. [表现 1]
2. [表现 2]
3. [表现 3]

发生的时间/频率：[描述问题什么时候发生，发生频率]

已采取的措施和效果：
[描述已经试过什么方法，效果如何]

请帮我做根本原因分析：

1. 现象罗列
   - 把观察到的所有现象列出来

2. 可能的原因假设（分维度）
   - 人的原因？
   - 流程的原因？
   - 技术的原因？
   - 外部环境的原因？

3. 原因验证
   - 怎么验证每个原因是不是真的？
   - 需要什么数据/信息？

4. 根本原因判断
   - 最可能的 3 个根本原因是什么？
   - 为什么是这 3 个？

5. 解决建议
   - 针对每个根本原因，给出具体的解决方案
   - 方案的优先级排序（紧急/重要）
   - 预期效果和实施难度评估
```

## 分析类 Prompt 技巧

1. **给数据的同时给背景**：AI 了解背景后分析质量更高
2. **要求结构化输出**：列表、表格、分点，清晰易读
3. **指定分析框架**：SWOT、PEST、5W2H 等，AI 会用得很好
4. **让 AI 给建议，不只是分析**：分析是为了行动
5. **交叉验证**：重要决策可以让 AI 分析后，自己再验证
