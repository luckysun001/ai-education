## 商务邮件

### 模板 1：写一封正式商务邮件

适用场景：给客户、合作伙伴写邮件

```
你是一位专业的商务人士，拥有 10 年的商务沟通经验。

请帮我写一封商务邮件，具体信息如下：

收件人：[收件人姓名/职位]
发件人：[你的姓名/职位]
邮件主题：[邮件主题]

背景信息：
[描述背景情况]

邮件目的：
[说明你写这封邮件想要达到什么目的]

要求：
1. 语气：[正式/友好/委婉/坚决]
2. 字数：控制在 [200] 字左右
3. 结构：称呼、正文、结尾、签名
4. 风格：专业、简洁、有说服力

请直接给出完整的邮件内容。
```

---

### 模板 2：邮件回复

适用场景：回复收到的邮件

```
你是一位专业的商务助理。

我收到了一封邮件，内容如下：

[粘贴邮件内容]

请帮我写一封回信，要求：
1. 对对方提出的 [要点 1] 表示同意/感谢
2. 针对 [要点 2] 进行说明
3. 提出下一步计划：[你的计划]
4. 语气：[友好/正式]
5. 不要超过 300 字

请直接给出完整的邮件回复。
```

## 会议纪要

### 模板 3：会议纪要整理

```
你是一位专业的行政助理，擅长整理会议纪要。

以下是会议的录音文字记录：

[粘贴会议记录]

请帮我整理成清晰的会议纪要，包含以下部分：

1. 会议基本信息
   - 会议时间：
   - 参会人员：
   - 会议主题：

2. 讨论要点
   - 按议题分类列出

3. 达成的共识
   - 列表形式

4. 待办事项
   - 责任人 + 截止日期

5. 下次会议安排

要求：
- 简洁明了，重点突出
- 总字数不超过 500 字
- 用 Markdown 格式
```

## 文案写作

### 模板 4：产品文案

```
你是一位资深的市场营销文案撰稿人，拥有 8 年的 4A 广告公司经验，擅长写有说服力的产品文案。

请为以下产品写一份文案：

产品名称：[产品名]
产品特点：
1. [特点 1]
2. [特点 2]
3. [特点 3]

目标用户：[描述目标用户群体]
核心卖点：[一句话说明为什么用户要买这个产品]

使用场景：
[描述用户在什么情况下会使用这个产品]

文案要求：
1. 文案类型：[海报文案/朋友圈文案/产品详情页/公众号推文]
2. 字数：[100] 字左右
3. 风格：[亲切友好/专业权威/年轻活力/高端奢华]
4. 要有号召力，能促使用户行动
5. 结尾加上行动号召（Call to Action）
```

---

### 模板 5：社交媒体文案

```
你是一位社交媒体运营专家，擅长写能引起互动的朋友圈/公众号/小红书文案。

请帮我写一篇 [小红书/朋友圈/微博] 文案，主题是：[主题]

核心信息：
1. [信息点 1]
2. [信息点 2]
3. [信息点 3]

要求：
1. 开头要有吸引力，能抓住眼球
2. 内容要有价值，用户看完觉得有用
3. 语言风格：[轻松口语化/专业/文艺]
4. 加上合适的 Emoji
5. 结尾引导互动（提问、转发等）
6. 字数：[200] 字左右
7. （小红书）最后加上相关的 Hashtag
```

## 文章润色

### 模板 6：文章润色优化

```
你是一位有 20 年经验的资深编辑，擅长把文章改得更清晰、更有说服力。

请帮我润色以下文章：

[粘贴文章内容]

润色要求：
1. 保持原文的核心意思不变
2. 让逻辑更清晰，结构更合理
3. 语言更流畅、更专业
4. 删掉冗余的内容
5. 修正语法错误
6. 目标读者是：[说明目标读者]

请先给出修改后的完整文章，然后用列表形式说明主要做了哪些修改。
```

---

### 模板 7：改变文章语气

```
你是一位写作专家，擅长调整文章的语气风格。

请把以下文章改写成 [更正式/更口语化/更年轻活力/更简洁] 的风格：

[粘贴文章内容]

要求：
1. 保持原文的所有信息点不丢失
2. 语气：[具体描述想要的语气]
3. 目标读者：[目标读者群体]
4. 使用场景：[描述使用场景]

请直接给出修改后的文章。
```

## 内容总结

### 模板 8：长文章总结

```
你是一位耐心的研究助理，擅长总结归纳。

请帮我总结以下长文章/报告：

[粘贴文章内容]

请按以下格式输出：

## 核心观点（3-5 条）
- [观点 1]
- [观点 2]
- [观点 3]

## 关键数据
- [数据 1]
- [数据 2]

## 建议/行动项
- [建议 1]
- [建议 2]

## 我的疑问（基于文章内容）
- [可以继续追问的问题]

要求：
- 总结要准确，不要遗漏重要信息
- 语言简洁，总字数控制在 300 字以内
- 用列表形式，清晰易读
```

## 通用写作

### 模板 10：从零开始写文章大纲

```
你是一位内容策划专家，擅长设计文章结构。

我想写一篇关于 [主题] 的文章，目标读者是 [读者群体]。

文章的核心目的是：[说明文章想要达到什么目的]

请帮我设计一个完整的文章大纲，包含：

1. 文章标题（3 个备选）
2. 引言（如何开头，吸引读者）
3. 主体部分（分几个部分，每个部分写什么）
4. 每个部分的核心要点
5. 结尾（如何收尾，留下深刻印象）
6. 预估字数

要求：
- 结构清晰，逻辑顺畅
- 符合目标读者的阅读习惯
- 有实用价值，不是空泛的理论
```

---

## 使用技巧

1. **先给角色，再给任务**：输出质量会好很多
2. **指定字数**：避免 AI 写得太长或太短
3. **要求格式**：用 Markdown、列表、表格，可读性更好
4. **不满意就迭代**：可以让 AI 按你的反馈继续修改
5. **积累好模板**：把反复用的模板保存下来，越用越顺手
