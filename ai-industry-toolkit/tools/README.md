## 一、先选类别，再选工具

新手最常见的低效是：**拿着一个工具找用途**。
正确顺序是反过来——先明确任务属于哪一类，再在那一类里挑。

```text
我的任务是什么？
  ├─ 产出文字（写/改/译/总结）  → 写作与润色类
  ├─ 产出图片/视频/音频          → 图像与设计类 / 音视频类
  ├─ 处理表格/数据/图表          → 数据分析类
  └─ 重复操作/跨平台搬运/定时做  → 自动化与 Agent 类
```

**一条重要提醒**：绝大多数"我该用哪个 AI 工具"的纠结，其实答案都是
**"你已经在用的那个对话助手就够了"**。只有当它明确做不好时，才值得换专用工具。

## 二、四类工具速查表

> 工具迭代很快，下表只列**类别定位与选型要点**，具体产品名称请以
> [《常用工具介绍》](../getting-started/03-common-tools.md)中的最新清单为准。

### 1. 写作与润色类

| 用途 | 选型要点 | 常见坑 |
|------|---------|--------|
| 长文档理解与总结 | 选**上下文长**的，能一次读完 | 文档太长时它会"忘掉"中间部分，超长材料要分块 |
| 中文公文/报告写作 | 选**中文语感好**的，国产模型往往更自然 | 直接输出常有空话，要给格式和字数约束 |
| 翻译 | 选支持**术语表/上下文**的 | 专业术语要提供对照表，否则译法前后不一致 |
| 批量改写 | 选支持**批量/接口调用**的 | 一次给太多条，后半段质量会明显下降 |

### 2. 图像 / 设计类

| 用途 | 选型要点 | 常见坑 |
|------|---------|--------|
| 概念图、氛围图 | 艺术感强的模型 | 出图好看但不可控，不适合需要精确还原的场景 |
| 带文字的海报 | 选**中文字形正确**的（这点国产工具通常更好） | 多数图像模型写不对中文，会出现乱码字 |
| 商品图 / 人像修图 | 选支持**局部重绘**的 | 整图重生成会改掉你不该改的部分 |
| 批量出图（同一风格） | 选支持**风格参考/固定种子**的 | 不固定参考，十张图十个风格 |

### 3. 数据分析与表格类

| 用途 | 选型要点 | 常见坑 |
|------|---------|--------|
| 表格清洗、公式生成 | 直接用对话助手，贴表格或描述结构即可 | **别让它做精确计算**，算数请用表格软件 |
| 从数据里找结论 | 让它"先看数据再给结论"，并要求说明依据 | 它会编造数据中不存在的趋势 |
| 图表生成 | 让它给图表代码或配置，你在专业工具里渲染 | 直接让它画出来的图通常不好看也不好改 |
| 大规模数据处理 | 用脚本/表格软件，AI 只负责写脚本 | 别让 AI 逐行处理上千条数据 |

### 4. 自动化与 Agent 类

| 用途 | 选型要点 | 常见坑 |
|------|---------|--------|
| 定时重复任务 | 选支持**定时触发**的自动化平台 | 无人值守的任务必须有失败告警 |
| 跨平台搬运（表单→表格→通知） | 选支持**多系统连接**的自动化工具 | 字段映射错了不会报错，只会静默出错 |
| 需要"自己规划步骤"的任务 | 用 Agent / 智能体（见 [AI 智能体入门](../getting-started/04-ai-agent.md)） | 一次性让它干太多，中途跑偏很难发现 |
| 读写本地文件、查数据库 | 需要能**连接外部数据源**（见 [MCP 是什么](../getting-started/05-mcp.md)） | 权限要收紧，别给超出需要的访问范围 |

## 三、选型决策：5 个问题定下来

遇到"要不要上新工具"时，按这 5 个问题过一遍，通常 2 分钟就能有结论。

| # | 问题 | 如果答案是… |
|---|------|------------|
| 1 | 我现在用的工具**明确做不好**哪一点？ | 说不出来 → 不用换 |
| 2 | 这个工具是**专门解决这一点**的吗？ | 只是"顺带能做" → 大概率不如现用工具 |
| 3 | 它要我**改变现有工作流**吗？ | 改动越大，落地概率越低 |
| 4 | 每周会用**超过 3 次**吗？ | 低于 3 次 → 先别付费，用免费额度验证 |
| 5 | 它产生的数据**能导出**吗？ | 不能导出 → 谨慎，别把资产锁死 |

> **第 1 问最关键。** "听说很好用"不是换工具的理由，"我现在这个在某件事上明确不行"才是。

## 四、组合用法：让工具串起来

单个工具的提升有限，**串起来才有量级变化**。三个可复用的组合：

**组合 A：资料 → 摘要 → 写作**
```
长文档/网页 → 对话助手提取要点 → 按要点生成初稿 → 你修改定稿
```
适用：行业研究、竞品分析、周报月报。

**组合 B：数据 → 分析 → 图表**
```
表格数据 → AI 给出分析思路与结论 → 生成图表代码 → 在专业工具渲染
```
适用：经营分析、用户分析、汇报材料。

**组合 C：触发 → 处理 → 通知**
```
定时/事件触发 → 自动化平台拉数据 → AI 处理成结论 → 推送到群/邮件
```
适用：每日简报、异常告警、线索跟进。

> 搭组合时先手工跑通一遍再自动化——**自动化只会放大流程的错误，不会修正它。**

## 五、维护你的工具清单

建议用一张简单的表长期维护，每季度更新一次：

| 场景 | 现用工具 | 付费与否 | 上次验证时间 | 已知不足 |
|------|---------|---------|------------|---------|
| 长文总结 |  |  |  |  |
| 中文写作 |  |  |  |  |
| 数据整理 |  |  |  |  |
| 图像生成 |  |  |  |  |
| 自动化 |  |  |  |  |

**"上次验证时间"这一列最重要**：工具能力变化很快，半年没重新验证过的判断基本已经过时了。

## 如何贡献

1. 发现更好用的工具或更好的用法，在 [prompt-library/](../prompt-library/) 补充对应场景的提示词；
2. 在本页对应类别的表格里补充选型要点或常见坑；
3. 参考 [入门指南](../getting-started/README.md) 的规范提交。

**我们更想要"选型经验"而不是"工具名单"**——名单会过期，
"这类任务该看什么指标去选"不会。
