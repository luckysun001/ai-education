# 贡献指南

欢迎参与贡献！这个项目因为有你的参与而变得更好。

## 可以贡献什么

### 1. 分享行业应用经验
如果你在某个行业有 AI 应用的实战经验，非常欢迎分享：
- 你所在行业可以用 AI 做什么？
- 有哪些好用的 Prompt？
- 踩过哪些坑？有什么经验教训？

### 2. 补充 Prompt 模板
如果你有珍藏的好用 Prompt，欢迎分享到对应的分类中。

### 3. 推荐 AI 工具
发现了好用的 AI 工具？欢迎补充到工具推荐中。

### 4. 实战案例
分享你用 AI 解决实际问题的完整案例。

### 5. 翻译/校对
帮助翻译文档，或修正现有文档的错误。

### 6. 其他
提出改进建议、优化文档结构、设计 Logo 等等。

## 如何贡献

### 方式一：提 Issue
如果你只是想提建议、反馈问题，直接提 Issue 就可以。

Issue 标题建议：
- `[建议] xxxxx`
- `[错误] xxxxx`
- `[求助] xxxxx`
- `[分享] xxxxx`

### 方式二：Pull Request
如果你想直接修改或添加内容：

1. **Fork 本仓库**
   - 点击页面右上角的 Fork 按钮

2. **创建新分支**
   ```bash
   git checkout -b my-contribution
   ```

3. **进行修改**
   - 修改对应的文件
   - 保持 Markdown 格式规范
   - 注意使用清晰的标题和结构

4. **提交更改**
   ```bash
   git add .
   git commit -m "描述你做了什么修改"
   ```

5. **发起 Pull Request**
   - 到你的 Fork 仓库页面
   - 点击 New Pull Request
   - 填写修改说明
   - 提交

6. **等待审核合并**
   - 维护者会尽快审核
   - 可能会有一些修改建议
   - 通过后就会合入主分支！

## 内容规范

### Markdown 规范
- 标题层级清晰（#、##、###）
- 列表使用 `-` 或 `1.`
- 重要内容加粗
- 适当使用表格整理对比信息
- 链接格式正确

### 内容要求
- **实用优先**：内容要能真正帮助到别人
- **中立客观**：避免过于主观的评价
- **结构清晰**：方便读者快速找到需要的信息
- **语言通俗**：避免过多专业术语，非技术人员也能看懂
- **尊重原创**：引用他人内容请注明来源

### 不要做的
- 不要发布违法违规内容
- 不要发广告、推广信息
- 不要包含敏感数据
- 不要攻击、贬低任何产品或个人
- 不要提交 AI 生成的垃圾内容（没有实际价值）
