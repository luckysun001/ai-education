# Prompt 入门指南

写出有效的 Prompt，提升 AI 输出质量。

## 什么是好的 Prompt？

好的 Prompt 应该具备以下特点：
- **清晰明确**：AI 知道你要什么
- **信息充分**：提供必要的背景
- **有边界**：告诉 AI 不要做什么
- **可执行**：给出明确的输出要求

## Prompt 写作黄金法则

### 法则 1：越具体，结果越好

❌ 不好的例子：
```
帮我写一份报告
```

✅ 好的例子：
```
帮我写一份关于最近一年 AI 行业发展趋势的市场分析报告，要求：
1. 字数：约 2000 字
2. 结构：摘要、主要趋势、机会与挑战、总结
3. 风格：专业、数据驱动
4. 目标读者：企业决策者
```

---

### 法则 2：给 AI 设定角色

让 AI 扮演某个专业角色，输出质量会大幅提升。

❌ 不好的例子：
```
帮我改一下这段文字
```

✅ 好的例子：
```
你是一位有 20 年经验的资深编辑，擅长写简洁有力的商业文案。
请帮我润色以下产品介绍文字，要求：
- 保留核心信息
- 更有说服力
- 控制在 200 字以内
- 适合放在官网首页

需要润色的文字：
[你的文字]
```

常用角色模板：
- 你是一位资深的市场营销专家...
- 你是一位有 10 年经验的软件工程师...
- 你是一位专业的文案撰稿人...
- 你是一位耐心的老师...

---

### 法则 3：明确输出格式

告诉 AI 你想要什么格式的输出。

格式选项：
- 列表（要点 1、要点 2、要点 3）
- 表格
- JSON/XML
- 邮件格式
- Markdown
- 代码块

例子：
```
请用表格形式列出以下三款产品的对比：
产品 A、产品 B、产品 C

表格列：价格、核心功能、优缺点、推荐指数
```

---

### 法则 4：提供例子

如果你有参考样例，直接给 AI 看。

例子：
```
请按照以下风格写一封商务邮件：

[示例邮件内容]

新邮件的背景：
[你的背景信息]
```

---

### 法则 5：分步思考

对于复杂问题，让 AI「先思考，再回答」。

技巧：加上「让我们一步一步来想」

例子：
```
我想在 3 个月内学会用 AI 提升工作效率，让我们一步一步来想：
1. 首先分析我的工作内容哪些可以用 AI
2. 然后制定学习计划
3. 推荐学习资源
4. 设定里程碑和评估标准

我的工作是：市场营销专员
```

## Prompt 万能模板

```
# 角色设定
你是 [专业角色]，拥有 [X 年经验]，擅长 [技能领域]。

# 任务描述
请帮我 [具体要做什么]。

# 要求
1. [要求 1]
2. [要求 2]
3. [要求 3]

# 背景信息
[提供必要的上下文]

# 输出格式
[列表/表格/Markdown/其他]

# 输入内容
[你的具体内容]
```

## 常用 Prompt 技巧

### 技巧 1：让 AI 提问
如果你不知道需要提供什么信息，可以让 AI 问你。

例子：
```
我想写一份商业计划书，你觉得我需要先告诉你哪些信息？
请列出最重要的 10 个问题。
```

### 技巧 2：迭代优化
不要指望一次就得到完美结果，可以让 AI 逐步优化。

例子：
```
刚才的回答不错，但我希望：
1. 更简洁一些，控制在 500 字以内
2. 数据部分再具体一点
3. 增加一个实际案例
```

### 技巧 3：让 AI 自评
让 AI 自己评估输出质量。

例子：
```
请评估一下你刚才的回答，从以下几个维度打分（1-10分）：
- 准确性
- 完整性
- 实用性
- 可读性

然后说明可以如何改进。
```

### 技巧 4：追问细节
对 AI 回答中你感兴趣的部分，可以继续追问。

例子：
```
请详细展开说明一下你刚才提到的第三点
```

### 技巧 5：提供约束
告诉 AI 不要做什么。

例子：
```
- 不要使用过于专业的术语
- 不要超过 300 字
- 不要提到竞争对手的名字
- 不要使用负面词汇
```

## 不同场景的 Prompt 示例

### 场景 1：写邮件
```
你是一位专业的商务人士。
请帮我写一封给客户的邮件，主题是：感谢合作并期待后续机会。

背景信息：
- 刚完成了一个为期 3 个月的项目
- 客户对结果很满意
- 希望能有更多合作机会
- 收件人是：王总

要求：
- 语气真诚、专业
- 字数控制在 200 字左右
- 不要显得太功利
- 结尾附上联系方式
```

---

### 场景 2：数据分析
```
你是一位资深的数据分析师。

以下是我们过去 6 个月的销售数据：
[粘贴数据]

请帮我：
1. 分析整体趋势
2. 找出表现最好和最差的月份
3. 分析可能的原因
4. 给出 3 条具体的改进建议
5. 用表格形式呈现关键指标
```

---

### 场景 3：会议纪要
```
你是一位专业的行政助理。

以下是会议录音的文字记录：
[粘贴会议记录]

请帮我整理成会议纪要，包含：
1. 会议基本信息（时间、参会人员）
2. 讨论要点（按议题分类）
3. 达成的共识
4. 待办事项（责任人 + 截止日期）
5. 下次会议安排

要求：简洁明了，重点突出，不超过 500 字。
```

---

### 场景 4：代码辅助
```
你是一位有 10 年经验的 Python 开发工程师，擅长编写清晰、可维护的代码。

我需要写一个函数，功能是：
[描述需求]

请帮我：
1. 写出完整的函数代码
2. 加上详细的注释
3. 写 3 个测试用例
4. 说明可能的边界情况
5. 给出性能优化建议
```

---

### 场景 5：学习新东西
```
你是一位耐心的老师，擅长用简单的语言解释复杂的概念。

我想学习 [某个主题]，我目前的水平是 [初学者/有一定基础/很熟悉]。

请帮我：
1. 用最简单的语言解释这个概念
2. 用一个生活中的例子说明
3. 列出学习这个主题的路线图
4. 推荐 3 个最好的学习资源
5. 给出前 3 周的练习计划
```

## Prompt 避坑指南

### ❌ 不要太简短
太简短的 Prompt 会让 AI 猜你的意图，结果往往不理想。

### ❌ 不要一次问太多问题
把复杂问题拆分成多个简单问题，质量更高。

### ❌ 不要期望一次就完美
好的结果往往需要 2-3 轮的迭代优化。

### ❌ 不要使用模糊的词
「写得好一点」「专业一点」这种描述没有意义。
应该说：「使用行业术语」「引用数据」「结构分 5 部分」。

### ❌ 不要怕写太长
Prompt 长一点没关系，只要信息清晰。

## 进阶技巧

### 技巧 1：思维链 (Chain of Thought)
让 AI 把思考过程写出来。

加上这句话：
```
请先一步步解释你的思考过程，然后再给出最终答案。
```

这会显著提升复杂推理的准确性。

### 技巧 2：少样本学习 (Few-shot Learning)
给 AI 看 2-3 个例子，效果会大幅提升。

### 技巧 3：自我一致性
让同一个问题问 AI 多次，取出现次数最多的答案。

### 技巧 4：工具调用
很多 AI 现在可以联网、查数据库、写代码并执行。善用这些能力。

## 练习建议

1. **每天练 3 个 Prompt**：把工作中遇到的问题都试试用 AI 解决
2. **建立自己的 Prompt 库**：把好用的 Prompt 记录下来
3. **多尝试不同模型**：不同模型适合不同任务
4. **记录效果**：记录哪个 Prompt 效果好，为什么
5. **和他人交流**：看看别人是怎么写 Prompt 的

## 总结

好的 Prompt = 清晰的角色 + 具体的任务 + 明确的要求 + 充分的背景

记住：Prompt 是和 AI 沟通的语言，写得越好，AI 表现越好。

熟能生巧，用得多了，自然就会了！
