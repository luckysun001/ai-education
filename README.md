## 💡 系列特点

### 🎯 实用导向，不讲废话

不讲原理，不讲数学，不讲底层技术，只讲你工作和生活中真正能用的东西。

### 💯 100% 可落地，照着做就行

每个场景都有完整的、可以直接复制粘贴用的 Prompt，每个工具都告诉你值不值得买，大概多少钱。

### 👨‍💼 面向真实的普通人

不是给专家和算法工程师写的，是给每天要上班、要写文档、要开会、要做事情的普通人写的。

### 🧠 不仅教你怎么用，还教你什么不能用

每个职业、每个行业都有专门的避坑指南，告诉你哪些红线不能碰，哪些错误大家最容易犯。

### 🔓 完全开源免费

所有内容完全开源免费，MIT 协议，任何人都可以用、可以改、可以分发，甚至可以用来赚钱。

## ❓ 常见问题

### Q：这些内容会不会过时？
A：核心的思路和方法不会过时，具体的工具和模型名字可能会变，但是怎么用 AI 的思维方式是不会变的。我们会定期更新内容。

### Q：我完全不懂技术，能学会吗？
A：可以。这个系列里的 90% 的内容都不需要你懂任何技术，会用电脑、会上网就能学会。

### Q：有问题去哪里问？
A：可以在 GitHub 提 Issue，或者看每个项目的 CONTRIBUTING.md 里有联系方式。

### Q：可以用来做培训或者课程吗？
A：MIT 协议，你可以随便用，可以用来做免费或者收费的课程都可以，但是希望你能注明一下来源就好。

### Q：怎么贡献内容？
A：非常欢迎！看每个项目的 CONTRIBUTING.md，按照流程来就可以。

## 🔗 相关项目

本系列专注「**怎么用** AI」——给你场景、Prompt 和工具选型，不碰底层原理。

如果你用顺手之后想再往深走一层，搞清楚「**为什么**能这么用」，推荐看作者的另一个开源项目：

> 系统化 AI 学习项目，每个知识点都配「原理讲解 + 标准伪代码 + 可运行实战」，
> 覆盖从传统机器学习到多智能体系统的完整路径。

| | 本系列（开源 AI 实战指南） | AI-Learning-Playground |
|---|---|---|
| **面向谁** | 普通职场人、非技术背景 | AI 学习者、想搞懂原理的人 |
| **讲什么** | 场景 Prompt、工具选型、避坑指南 | 算法原理、伪代码、可运行代码 |
| **解决什么** | 今天就能用起来 | 建立完整知识体系 |
| **要不要写代码** | 基本不用 | 需要跑代码 |

**两者互补**：先用本系列解决眼前的具体问题，再用 Playground 补上原理功底。
