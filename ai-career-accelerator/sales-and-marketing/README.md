## 📅 销售每日 AI 工作流

### 上班第一件事（10 分钟）：规划今天的跟进

```
你是我的销售助理。
我手上现在有这些客户：[简单列一下你今天要跟进的客户，每个客户说一下现在是什么阶段]

昨天的进展是：[昨天跟进了谁，怎么样了]

今天的目标是：[今天想搞定什么事情]

请帮我：

1. 把今天要跟进的客户按优先级排序，说明理由
   - 哪些客户今天必须跟进，不跟就黄了？
   - 哪些客户可以缓一缓？
   - 哪些客户今天跟进成功率最高？

2. 每个客户的跟进策略
   - 这个客户现在是什么阶段？
   - 今天跟进的目标是什么？（推进到下一个阶段 / 问预算 / 约演示 / 逼单 等）
   - 应该用什么方式跟进？（电话 / 微信 / 邮件）
   - 大概什么时候发/打比较合适？

3. 每个客户的话术初稿
   - 给我一个开场怎么说的初稿
   - 我可以直接改改就用

4. 今天的时间规划
   - 上午做什么？下午做什么？
   - 哪些事情要先做？哪些可以放后面？
```

### 给客户发消息之前（5 分钟）：先让 AI 给你 3 个版本话术

```
我要给 [客户名字，什么公司的，什么职位] 发 [微信 / 邮件 / 短信]
这个客户现在的阶段是：[比如：刚加好友 / 发了资料还没回 / 约演示 / 谈价格 等]
我这次找他的目的是：[比如：约个时间聊聊 / 问一下考虑得怎么样了 / 发一下方案 等]
之前我们聊过的内容是：[简单说一下之前的沟通背景]
想要的风格是：[比如：专业正式 / 亲切随意 / 有一点紧迫感 / 不要太推销]

请帮我写 3 个不同风格的话术版本：
1. 版本 A：直接明了，不绕弯子
2. 版本 B：亲切自然，像朋友聊天
3. 版本 C：稍微正式一点，适合比较大的客户

每个版本 100 字以内，不要太长，
开头要怎么说，中间说什么，结尾怎么引导回复，
最后给我建议用哪个版本，为什么。
```

### 客户拒绝之后（10 分钟）：让 AI 帮你分析和想对策

```
我跟客户 [客户名字] 沟通了，
客户说：[客户原话，比如：太贵了 / 我们再想想 / 现在预算不够 / 老板不同意 等]
当时我是这么回的：[你当时怎么说的]
现在的情况是：[现在是什么状态]

请帮我分析一下：

1. 客户说这句话，真正的意思是什么？是真的贵，还是只是议价的手段？还是根本不想买，找个借口？
2. 我当时的回应对不对？有没有什么问题？
3. 接下来我应该怎么跟进？
   - 给我 3 个不同的跟进策略
   - 每个策略的优缺点是什么？
   - 你推荐哪个？为什么？

4. 下次跟进怎么说？给我话术初稿
5. 这个客户赢单的概率还有多少？值不值得继续花时间跟进？
6. 有没有什么其他的切入点可以试试？
```

### 写方案之前（30 分钟）：先让 AI 帮你搭框架

```
我要给 [客户公司] 写一个方案，
客户的背景是：[简单说一下客户是做什么的，什么行业，什么规模]
客户的痛点和需求是：[客户说他们有什么问题，想要什么]
我们的产品/服务是：[简单说一下我们卖什么，能帮客户解决什么问题]
方案的目标是：[写这个方案想要达到什么效果，比如：让客户觉得我们专业 / 推进到报价阶段 / 说服老板买单 等]

请帮我搭一个方案的框架：

1. 这个方案应该分几个部分？每个部分写什么？
2. 哪些部分是客户最关心的，要重点写？
3. 哪些部分可以一笔带过，不用写太多？
4. 怎么写能让客户觉得我们懂他们的业务？
5. 怎么写能突出我们的优势，和竞品不一样？
6. 怎么写能让客户看完就想跟我们继续聊，而不是说「我再想想」？
7. 给我一个完整的目录和每个部分的写作要点
8. 再给我一个 1 页纸的 Executive Summary 版本，用来给客户老板看的
```

### 写周报/月报/汇报之前（15 分钟）：让 AI 帮你整理

```
我这个月的销售数据是：
[列一下你的核心数据：拜访了多少客户，新增了多少线索，多少演示，多少提案，多少成单，多少金额，完成率多少，等等]

这个月做得好的地方是：
[简单说一下]

这个月做得不好的地方是：
[简单说一下]

下个月的目标和计划是：
[简单说一下]

请帮我写一份销售月报，给老板看的：

1. 开头先总述一下这个月的整体情况，一段话
2. 核心数据部分，用表格呈现，加一点分析
   - 哪些数据好？为什么？
   - 哪些数据没达标？为什么？
3. 亮点和成果部分，分点说，3-5 点
4. 问题和不足部分，分点说，3-5 点，每个问题要有对应的改进措施，不要只说问题不说怎么办
5. 下个月的目标和行动计划
6. 需要公司和老板支持的地方

语言风格要专业，数据要清晰，
不要太装逼，也不要太谦虚，
做得好的地方要体现出来，
做得不好的地方要有解决方案，让老板放心。

最后再给我一个 3 分钟的口头汇报版本，开会的时候我直接讲。
```

## 🧠 核心场景 Prompt 模板

### 场景 1：客户背景调研和画像

```
我要去见一个客户，
客户公司是：[公司名字，做什么的，什么行业，多大规模]
我要见的人是：[名字，职位，大概什么背景]

请帮我做客户背景调研：

1. 这家公司最近的动态
   - 最近有没有融资？有没有上新产品？有没有什么大新闻？
   - 最近的战略方向是什么？
   - 有没有什么负面新闻？

2. 这家公司可能的痛点和需求
   - 这个行业的公司一般都有什么痛点？
   - 他们这个阶段最关心什么问题？
   - 我们的产品/服务可能在哪些地方帮到他们？

3. 我要见的这个人的背景
   - 这个人大概是什么背景？
   - 他在公司多久了？
   - 他这个职位一般最关心什么 KPI？
   - 他最在意什么？最担心什么？
   - 跟他说话要注意什么？

4. 见面可以聊的破冰话题
   - 哪些话题是安全的，可以拉近距离的？
   - 哪些话题最好不要碰？

5. 见面前的准备清单
   - 我应该提前准备什么东西？
   - 哪些问题可以问？哪些问题最好不要问？
   - 第一次见面，我的目标应该是什么？（不要指望第一次就成交，合理一点）

6. 可能的异议和应对
   - 他最可能会说什么话来拒绝我？
   - 我应该怎么应对？
```

### 场景 2：异议处理和谈判话术

```
客户说：[客户的异议，比如：太贵了 / 我们再想想 / 我们现在不需要 / 老板不同意 / 某某竞品比你们便宜 等]

请帮我想 5 个不同的回应方式：

1. 方式一：认同 + 转折
   - 先认同客户的说法，不要反驳，然后再转折说我们的价值
2. 方式二：提问，了解真正的异议
   - 不要直接回答，而是提问，了解客户真正担心的是什么
3. 方式三：价值塑造，讲 ROI
   - 不算多少钱，算投资回报，算能帮客户省多少钱，赚多少钱
4. 方式四：类比和举例子
   - 举其他客户的例子，跟他情况一样的，用了之后怎么样了
5. 方式五：适当让步，换条件
   - 如果价格确实是问题，可以适当让步，但是要换点什么回来（比如签更长时间，介绍其他客户等）

每个方式都给我具体的话术，
要自然，不要像背书，
不要太推销，不要引起客户反感，
最后告诉我你推荐用哪个方式，在什么情况下用。
```

### 场景 3：逼单和促成交话术

```
这个客户已经跟进很久了，
现在的情况是：[简单说一下现在到什么阶段了，客户还有什么顾虑]
我感觉差不多可以逼单了，但是不知道怎么开口，
不想逼得太紧，把客户吓跑了，
也不想一直拖，拖黄了。

请帮我想 5 个不同的逼单方式：

1. 方式一：假设成交法
   - 直接假设他已经买了，问接下来的安排
   - 比如：「那我们下周一开始部署？还是下下周？」

2. 方式二：优惠截止法
   - 有个优惠/活动，到什么时候就截止了，现在定可以享受优惠

3. 方式三：痛点唤醒法
   - 再提一下他的痛点和问题，提醒他再拖问题还在那里，早解决早好

4. 方式四：降低门槛法
   - 不用一下子全买，可以先试点，先试一部分，风险小，效果好了再全量

5. 方式五：直接问法
   - 直接问：「王总，您看我们聊了这么久，您这边还有什么顾虑吗？还有什么我们没说清楚的吗？如果没有的话，我们就把这个事定下来？」

每个方式都给我具体的话术，
要自然，不要太有压迫感，
不要让客户觉得你在逼他，
要让他觉得你是在帮他解决问题。

最后告诉我每个方式适合什么情况，
你推荐用哪个，为什么。
```

### 场景 4：客户分层和 SOP 设计

```
我手上现在有 [多少] 个客户，
但是不知道怎么管理，不知道重点跟进谁，
经常漏跟进，或者在成不了的客户身上浪费太多时间。

请帮我设计一套客户分层和管理的方法：

1. 客户怎么分层？
   - 分几层比较合适？
   - 每层的定义和标准是什么？
   - 比如：A 类客户（7 天内可能成单）、B 类（30 天内）、C 类（30 天以上）、D 类（暂时没希望）

2. 每层客户的跟进策略
   - A 类客户多久跟进一次？怎么跟进？跟进目标是什么？
   - B 类客户多久跟进一次？怎么跟进？
   - C 类客户多久跟进一次？怎么跟进？
   - D 类客户怎么处理？直接放弃吗？还是偶尔维护一下？

3. 每个阶段的跟进 SOP
   - 第一次加好友之后怎么说？
   - 发了资料没回怎么跟进？
   - 聊了一次没下文了怎么跟进？
   - 报了价没回怎么跟进？
   - 客户说「再想想」怎么跟进？
   - 每个阶段给我一个标准话术模板

4. 客户管理工具和方法
   - 用什么工具管理客户比较好？
   - 怎么记录客户信息和跟进记录？
   - 怎么提醒自己跟进？
   - 怎么复盘和总结？

5. 时间怎么分配？
   - 每天多少时间花在 A 类客户身上？
   - 多少时间花在 B 类？
   - 多少时间花在新客户开发上？
   - 不要说 80% 时间在 20% 客户上这种废话，给我具体的时间分配建议
```

### 场景 5：客户成功和复购增购

```
这个客户已经成交了，
接下来我要做好客户成功，
让他用得好，给我介绍新客户，
还要复购和增购。

请帮我设计一套客户成交流程和维护方法：

1. 成交之后的第一周怎么做？
   - 成交当天怎么说？
   - 第一天怎么安排？
   - 第一周要做什么事情，让客户觉得选我们没错？
   - 怎么让客户快速用起来，看到效果？

2. 怎么定期回访和维护？
   - 多久回访一次？
   - 每次回访聊什么？不要每次都问「用得怎么样」，太干了
   - 怎么自然地了解客户有没有新的需求？
   - 怎么让客户愿意给你介绍新客户？

3. 怎么找复购和增购的机会？
   - 哪些信号说明客户可能有新的需求？
   - 怎么开口说增购的事情，不显得你只是想赚他钱？
   - 怎么推新产品和新服务？

4. 怎么让客户给你转介绍？
   - 什么时候开口要转介绍比较合适？
   - 怎么开口比较自然，不让客户有压力？
   - 客户给了转介绍之后，怎么感谢？怎么维护关系？

5. 客户用得不满意怎么办？
   - 客户投诉、抱怨怎么处理？
   - 怎么把不满意的客户变成满意的，甚至变成忠实客户？
   - 有哪些常见的坑要避免？
```

## 真实案例

### 案例 1：用 AI 写话术，回复率提升 2 倍

**背景**：某销售，给客户发跟进消息，发 10 个有 2 个回就不错了，大部分都石沉大海，不知道怎么回事。

**AI 用法**：
1. 把客户情况、跟进目标告诉 AI
2. 让 AI 写 3 个不同风格的话术版本
3. 选最合适的那个，自己再改一改语气，变成自己的话
4. A/B 测试，看哪个版本回复率高，以后就用哪个

**效果**：原来回复率 20% 左右，现在平均能到 40-50%，同样的时间，能联系上的客户翻了一倍，业绩自然也就涨了。

---

### 案例 2：用 AI 做客户背景调研，见面聊得特别投机，一次就搞定

**背景**：某销售，要见一个大客户的高管，之前完全不了解，不知道见面聊什么，很容易冷场，也不知道客户关心什么。

**AI 用法**：
1. 把客户公司名字、职位告诉 AI
2. 让 AI 做背景调研，查公司动态、行业痛点、这个职位关心的 KPI
3. 让 AI 想几个破冰的话题，客户可能感兴趣的
4. 让 AI 预测客户可能会问什么问题，提前准备好答案

**效果**：见面之后，跟客户聊行业、聊他们公司最近的动作、聊他关心的问题，客户觉得「你很懂我们」，特别投机，一次就把事情定了，客户说「见过这么多销售，你是第一个做了功课来的」。

## ⚠️ 避坑指南

### ❌ AI 写的话术，你一定要改成自己的话！不要直接发！

这是销售用 AI 最容易犯的错误：

- AI 写的话术太模板化，太像 AI，没有人味
- 一看就是复制粘贴的，客户一看就不想回
- AI 不了解你和客户的熟悉程度，语气可能不对

**重要原则：AI 是给你灵感和初稿的，不是给你写终稿的。**

你一定要：
1. 改成你自己平时说话的语气和风格
2. 加上只有你和客户知道的细节，显得你不是群发的
3. 去掉那些很假、很官方的套话
4. 写得像你自己亲自想出来的，而不是复制粘贴的

直接把 AI 写的话术发出去，回复率一定很低。

---

### ❌ 不要让 AI 代替你跟客户沟通！

销售的核心是信任，是人与人的连接。
AI 可以帮你写初稿、帮你想策略、帮你分析，
但是**跟客户说话的人，必须是你**。

不要用 AI 自动跟客户聊天，
不要用 AI 假装是你跟客户打电话，
客户不是傻子，能感觉出来对面是不是真人。

AI 是你的助理，不是你的替身。

---

### ❌ 不要什么都让 AI 帮你想，你自己要有判断！

AI 可以给你 5 个跟进策略，
但是**哪个策略适合这个客户，这个客户值不值得继续花时间**，这个判断必须你自己来。

你是销售，你要为结果负责，AI 不用负责。
AI 不知道你跟客户聊的时候的语气、氛围、客户的表情和态度，
这些只有你知道。

---

### ❌ 绝对不要把客户的敏感信息喂给公有 AI！

- 客户的联系方式、个人信息
- 客户的预算、内部信息、保密的东西
- 你们的报价、合作细节、商业机密

这些东西，绝对不要粘贴到公有 AI 服务里。
如果要用，用你们公司自己部署的私有化模型。

不然出了问题，轻则丢客户，重则丢工作，甚至吃官司。

---

### ❌ 不要沉迷于用 AI 做体力活，忘了销售真正的核心能力！

AI 可以帮你写 100 条话术，
但是**能不能让客户信任你，能不能搞定人**，这个能力还是要你自己练。

不要每天就是坐在电脑前用 AI 发消息，
然后抱怨说现在客户怎么都不回。

多打电话，多见客户，多跟人聊，
这些才是销售真正的核心能力，
AI 是帮你节省时间，让你有更多时间去做这些事情，
而不是让你变得更宅，更不见人。

## 📅 30 天学习计划

### 第一周：基础入门，先把写话术这个技能练熟
- 第 1-2 天：练用 AI 写各种话术，微信、邮件、跟进、破冰等
- 第 3 天：练用 AI 做客户背景调研
- 第 4-5 天：练用 AI 做异议处理，各种常见拒绝的应对
- 周末：总结一下，把你最常用的 10 个话术场景的 Prompt 存下来，形成自己的话术库

### 第二周：进阶提升，解决实际问题
- 练用 AI 写方案和报价
- 练用 AI 写汇报和总结
- 练用 AI 做逼单和促成交

### 第三周：场景拓展
- 练用 AI 做客户分层和管理
- 练用 AI 做客户成功和复购增购
- 练用 AI 做市场调研和竞品分析

### 第四周：形成自己的工作流
- 把 AI 融入你每天的销售工作流里
- 沉淀自己的 Prompt 库和话术模板
- 知道什么场景 AI 帮得上忙，什么场景还是要靠自己
- 教团队里的其他销售也用起来，大家一起提升业绩

## 给销售的心里话

很多人觉得销售就是靠嘴皮子，就是靠喝酒，就是靠关系。
但其实现在的销售越来越专业，越来越靠方法，越来越靠效率。

同样一天 24 小时，
有的销售一天能跟进 5 个客户，
有的销售用了 AI 辅助，一天能跟进 20 个客户，
而且每个客户的跟进质量还更高，
业绩自然是别人的好几倍。

**AI 不会取代销售，但是会用 AI 的销售，会取代不会用 AI 的销售。**

拥抱 AI，把它变成你的超能力吧！🚀
