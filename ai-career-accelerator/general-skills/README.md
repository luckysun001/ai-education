## 1. AI 工具选择指南：哪些值得付费？

### 判断标准：先算一笔账

不要问"这个工具好不好"，要问**"它替我省下的时间值不值这个价"**：

```text
每月订阅费 ÷ 你的时薪 = 需要每月省下多少小时才回本
```

举例：订阅 ¥150/月，你的时薪 ¥100，那么每月只要省下 **1.5 小时**（约每天 4 分钟）就已经赚回来了。
对绝大多数知识工作者来说，**付费版几乎总是划算的**——真正的成本不是钱，是那 1.5 小时你本可以做别的事。

### 值得付费的三类场景

| 场景 | 为什么值得付费 | 典型表现 |
|------|--------------|---------|
| **高频使用**（每天都要用） | 免费版的额度限制和排队会在最忙的时候卡住你 | 对话助手、写作助手 |
| **能力差距明显** | 付费模型在长文档、复杂推理上质量显著更高 | 长报告总结、复杂数据分析 |
| **直接产生收入** | 输出质量直接影响客户付费与否 | 设计稿、文案、方案 |

### 可以先用免费版的三类场景

| 场景 | 理由 |
|------|------|
| **低频尝试**（一个月用几次） | 用不上付费额度，先验证是否真的需要 |
| **国产平替已经足够好** | 中文日常任务上，多家国产模型免费且够用 |
| **只是想体验** | 先跑通流程，确定高频了再付费 |

### 一条实用建议

> **不要同时订阅多个同类工具。**
> 先用透一个，遇到它明确做不好的事，再为那件事单独开一个订阅。
> 大多数人订阅 3 个以上同类工具的真实结果是：每个都用得不深，哪个都不顺手。

## 2. Prompt 核心技能清单：每个职业都该会的 10 个技巧

按「学了立刻能用」排序，前 5 条覆盖 80% 的日常场景。

### 第一梯队（必会）

**① 说清角色 + 任务 + 输出形式**
```
你是一位有 10 年经验的 [职业]。
请 [具体任务]。
输出形式：[字数/格式/条数]。
```
这三件套缺一个，输出质量就会明显下降。绝大多数"AI 不好用"的抱怨，都是因为只给了任务。

**② 给例子，别给描述**
想让 AI 模仿某种风格，与其花 200 字描述风格，不如直接贴 2 个例子：
```
参考下面两篇的风格，写一篇新的：
---例1--- ...
---例2--- ...
```

**③ 指定输出格式**
要求"用表格输出，三列：问题 / 原因 / 建议"，比"整理一下"强十倍。
要 JSON、要 Markdown、要分点——**明确说出来**。

**④ 让它先问你再动手**
```
在开始之前，先问我 3 个能显著提升输出质量的问题。
```
这能避免 AI 靠猜填补你没说清的关键信息。

**⑤ 分步骤，别一次要到底**
复杂任务拆成"先列大纲 → 确认后再逐节写"，质量远高于一次性生成长文。

### 第二梯队（进阶）

**⑥ 设定约束条件**：明确"不要什么"和"不要超过多少字"，比只说"要好"有效得多。

**⑦ 让它给理由**：`请给出结论，并说明你的推理过程。` 有推理链的输出，你能判断它对不对。

**⑧ 要求自我检查**：`完成后请自查：有没有事实错误？有没有遗漏我提的要求？` 一轮自查能拦掉大部分低级错误。

**⑨ 让它扮演反对者**：`请站在反对者立场，指出这个方案最可能失败的三个点。`

**⑩ 多轮迭代而非一次成型**：把 AI 当同事——先要初稿，再针对具体段落提具体意见。
**一次对话改 3 轮，效果远好于重新开 3 次对话。**

## 3. 效率提升清单：把日常效率提升 30%

30% 听起来不多，但折算下来是**每周多出半天**。关键是选对场景——AI 不是万能加速器。

### ✅ AI 最擅长的四类事（优先交给它）

| 场景 | 具体做法 | 典型节省 |
|------|---------|---------|
| **空白页启动** | 让它出大纲/初稿，你只做修改 | 从 1 小时 → 15 分钟 |
| **格式转换与整理** | 把乱文本变成表格、把长文变成要点 | 从 40 分钟 → 5 分钟 |
| **批量重复劳动** | 同样的结构批量生成 20 条 | 从半天 → 半小时 |
| **理解陌生材料** | 扔进长文档，让它解释并回答 | 从 2 小时 → 20 分钟 |

### ⚠️ AI 不擅长、别指望的三类事

- **需要你独有信息的事**：它不知道你公司的历史、你老板的偏好、客户的真实诉求
- **需要担责的判断**：可以要建议，但决策和后果仍在你
- **精确计算与最新事实**：算数用计算器，事实要查源

### 立即可执行的 7 天挑战

| 天 | 动作 | 预期收获 |
|----|------|---------|
| 第 1 天 | 记录今天最耗时的 3 件事 | 找到切入点 |
| 第 2 天 | 把其中 1 件交给 AI 做初稿 | 体验第一次提速 |
| 第 3 天 | 给自己写 3 个常用 Prompt 并保存 | 建立个人模板库 |
| 第 4 天 | 用 AI 总结一份你没时间读的长文档 | 掌握长文档处理 |
| 第 5 天 | 用 AI 做一次"反对者评审" | 学会用它做质量检查 |
| 第 6 天 | 把某个周报/汇报流程模板化 | 固化一个高频场景 |
| 第 7 天 | 复盘：哪件事省时最多，把它固定下来 | 形成习惯 |

> **衡量标准**：一周后问自己"哪件事我再也不想回到原来的做法"——
> 只要有 1 件，这 30% 就落地了。

## 4. 避坑指南：最容易犯的错误

### 坑 1：把 AI 的输出当事实

**表现**：直接复制数字、法条、案例就发出去。
**后果**：AI 会生成看起来非常合理但完全虚构的内容（编造的数据、不存在的案例、错误的引用）。
**怎么办**：**凡是会被别人核查的内容，必须自己核一遍源。**
数字查原文，案例查出处，法条查原文。AI 适合做草稿，不适合做证据。

### 坑 2：一次性丢一大段材料就等好结果

**表现**：贴 5000 字需求，说"帮我写个方案"。
**后果**：输出笼统、没重点、和你想要的差很远。
**怎么办**：先让它复述需求并提问，确认对齐后再分步产出。

### 坑 3：不设边界，什么机密都往里贴

**表现**：把客户名单、财务数据、未公开战略直接粘进对话框。
**后果**：可能造成数据泄露，且很多情况下不可撤销。
**怎么办**：**敏感信息先脱敏**——人名改代号、金额改量级、客户名改行业描述。
涉及合规要求的数据，遵循公司规定，别图省事。

### 坑 4：一个 Prompt 用到底

**表现**：同一个 Prompt 反复用，不随任务调整。
**后果**：输出千篇一律，AI 的潜力只用了两成。
**怎么办**：把好用的 Prompt 存成模板，但**每次按任务做 2-3 处针对性修改**。

### 坑 5：被第一版输出带跑

**表现**：AI 给了个方向不对的初稿，就在它的框架里反复修改。
**后果**：改了 5 轮还是不满意，时间反而花得更多。
**怎么办**：**判断"方向"比优化"细节"更早做**。
如果大纲就不对，立刻停下来重开一轮，而不是在错误的骨架上精修。

### 坑 6：只看结果，不学方法

**表现**：每次都当"抽取式工具"用，用完就走。
**后果**：半年后你的能力和半年前一样。
**怎么办**：遇到好的输出，多问一句"为什么这样写好"——
把 AI 的用法沉淀成你自己的方法论，这才是真正的复利。
