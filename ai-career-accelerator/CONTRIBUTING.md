# 贡献指南

非常感谢你对 AI 职业技能加速器的兴趣！我们非常欢迎任何形式的贡献。

## 🤝 如何贡献

### 1. 内容补充
- 增加新的职业
- 补充现有职业的新场景
- 改进 Prompt 模板
- 增加新的工具推荐
- 修复错误或者过时的内容

### 2. 翻译和本地化
- 翻译成其他语言
- 改进现有的翻译

### 3. 格式和排版
- 改进 Markdown 格式
- 增加图表和示例
- 优化阅读体验

### 4. 其他
- 报告 Bug
- 提出新的想法和建议
- 帮助解答其他人的问题

## 📝 提交 PR 的流程

1. Fork 这个项目
2. 创建你的 feature branch (`git checkout -b feature/amazing-feature`)
3. 提交你的修改 (`git commit -m 'Add some amazing feature'`)
4. Push 到分支 (`git push origin feature/amazing-feature`)
5. 开一个 Pull Request

## 📋 内容规范

### 内容质量
- 实用导向：写的内容必须是普通人工作生活中真正能用的
- 可落地：每个场景最好有可以直接复制的 Prompt
- 避坑：每个职业最好有专门的避坑指南
- 诚实：工具推荐要客观，好用就是好用，不好用就是不好用

### 格式规范
- 使用中文简体
- 标题层级清晰：# 一级，## 二级，### 三级
- 列表用 - 开头，不用数字
- 重要的东西用 **加粗** 或者 ⚠️ 标记
- Prompt 用代码块 ``` 包裹

### 风格指南
- 语气友好、平实、不讲废话
- 像和朋友聊天一样，不要太学术
- 避免行话和黑话，如果不可避免要解释清楚
- 不要有优越感，不要有「你连这个都不会」的感觉
